# 知行 Learnflow

中文 AI 自学与个人知识管理工具：**学习目标 → 个性化路线 → 课程与实践 → 练习答疑 → 知识卡片**。以 Windows 桌面版为主要使用入口，保留 Web 开发模式，支持本机模型和云端模型。

当前源码版本：`1.3.9`，以 [package.json](package.json) 为准。本文介绍当前工作区功能；已有安装包需要重新构建，才会包含源码中的最新修改。

## 主要功能

| 功能 | 当前能力 |
| --- | --- |
| 个性化路线 | 根据目标、基础、每日时间和周期澄清需求，生成 3–12 节课程 |
| 资料辅助教学 | 导入自己的 PDF、Word、Markdown、文本，或开启联网搜索；正文附可查看的原文引用 |
| 分块课程 | 讲解、配套案例、动手实践、随堂练习、知识总结；支持展开收起、换个讲法／例子／任务及版本恢复 |
| 随堂练习 | 首次固定 4 题，之后每次追加 1–5 题，每课最多 100 题；已通过题直接展示答案与解析 |
| 事实核查与评分 | 独立模型核查事实、引用和答案；支持疑点确认修正；课程评分单独只读展示 |
| 答疑与朗读 | 使用课程生成模型答疑；可选角色音色朗读、缓存重听和播放速度调整 |
| 课程配图 | 可选 AI 生成、百炼在线搜图或 Commons 图库，配图保存到本机 |
| 个人知识库 | 生成并编辑 Markdown 卡片、随文笔记、目录与主题管理、关联图谱、全文关键词检索及引用式问答 |
| 继续学习与任务 | 恢复上次章节、栏目和阅读位置；右下角展示生成阶段与耗时，进行中的任务可手动取消 |
| 数据与分享 | SQLite 本机存储、完整学习备份、课程包导入导出、Wiki Markdown 导出 |

资料导入、课程包、独立核查与评分、配图及朗读等完整流程以桌面版为准。未配置模型时，可先体验内置 Python 示例课程。

## 快速开始

### 使用 Windows 安装包或免安装版

- **安装版**：运行 `Learnflow-Setup-<版本>.exe`，安装后打开桌面“知行 Learnflow”快捷方式。
- **免安装版**：完整解压 ZIP，再运行其中的 `Learnflow.exe`，保留同目录的全部文件。
- 运行已打包程序不需要安装 Node.js。首次打开后进入“设置与数据”配置模型，或先体验示例。

### 从源码启动测试版

需要 **Node.js 22.16+** 和 npm。在项目根目录执行：

```powershell
npm ci
npm run desktop:dev
```

`desktop:dev` 默认打开模型设置页，数据保存在 `.desktop-dev/data/`，与已安装版本分开，可同时运行。首次使用需单独配置模型或导入学习备份，不会自动复制正式版配置。

`npm run desktop` 启动普通桌面模式，使用普通应用数据目录。修改源码后请重启对应测试版；旧安装包不会自动更新。

## 使用流程

1. **配置模型**：在“设置与数据 → 课程生成与答疑”保存模型配置，并检查连接。
2. **描述目标**：点击“开启新的学习”，填写目标、基础、每日投入和周期；需要时先导入学习资料并预览。
3. **预览并确认**：回答澄清问题后先预览课程大纲；不满意可补充要求或返回澄清，反复调整。满意后进入最终确认，才创建课程。
4. **展开课程**：进入章节，生成大纲与所需内容块；实践任务在自己的工具中完成。
5. **练习与答疑**：提交练习、查看解析、追加新题；答对的原题不必重复作答。右侧入口可进行 AI 答疑或朗读。
6. **积累与继续**：选中原文添加批注，或制作知识卡片。下次从首页“继续学习”恢复具体章节与栏目位置。

新建流程为“描述需求 → 澄清方向 → 大纲预览 → 确认生成”；预览期间不新增课程，最终确认直接保存认可的大纲，不重复调用模型。[调研与预览循环](docs/planning-preview-loop.md)

已创建课程的目录仍可调整：在课程目录顶部或学习路线页点击“调整课程目录”，补充要求并对照预览，确认后另存“调整版”。原课程和学习记录保留，调整版沿用需求、资料及手动分类，正文按新目录生成。[目录调整说明](docs/plan-adjustment.md)

### 课程分类与手动调整

“学习路线 → 我的课程分类”覆盖 AI、数据分析、办公自动化、语言沟通、财税法务、商业管理等 13 类，按标题优先的本地规则整理。支持搜索课程和分类，默认只展开当前课程所在类别，可逐类或全部展开收起。点击“调整分类”可批量修改；手动选择优先保存，选择“自动分类”恢复规则判断。分类不调用模型，随备份和课程包保留，并同步知识库领域。[分类规则](docs/course-classification.md)

### 三种课程生成方式

| 方式 | 使用方式与范围 |
| --- | --- |
| 普通生成 | 未绑定导入资料且关闭联网搜索时，依据当前模型和课程上下文生成 |
| 导入资料生成 | 大纲读取全部提取文字并逐项检查课程覆盖；正文按课程对应范围检索原文，不自动混入网页 |
| 联网资料生成 | 无导入资料的课程可打开“联网搜索”；生成模块时搜索并读取网页，优先官方和原始来源，过滤论坛、问答、自媒体等排除来源 |

**导入资料上限**：每门课程 20 份，每份 10 MB；单份文字最多 30 万字，全库合计 100 万字。支持可提取文字的 PDF、`.docx`、`.md`、UTF-8 `.txt`。扫描 PDF 需先 OCR，旧版 `.doc` 需另存为 `.docx`。

大纲按完整资料规划：短资料直接传入全文，长资料逐批整理全部片段，再检查每项对应哪些课程；预览及路线页可展开“资料覆盖清单”。长资料整理可能增加模型调用和等待时间；时间或处理容量不足时明确提示，不静默截断。正文仍每次选取最多 3 份资料、合计最多 19800 字符，优先对应课程的原文。引用可定位 PDF 页码、Word 提取段落、文本行号。资料保存为文字快照；图片、表格及公式的提取情况仍需预览核对。[详细规则](docs/course-local-materials.md)

**联网搜索**目前使用已配置的百炼文字模型及 Responses `web_search` 工具，需要相应模型和服务权限。读取来源采用排除策略，未被排除不代表已认证权威；无可读资料或引用不合格时停止该次生成。随堂练习只考已讲内容、复用有效引用，不重新搜索。[联网资料说明](docs/course-source-assisted-generation.md)

正文引用可点击查看来源，课末“参考文档”默认折叠。引用校验和独立核查只能帮助减少错误，不能保证零幻觉或证明每条结论正确。

### 质量审查、课程评分与生成任务

- **质量审查**：先配置不同于生成模型的“事实核查模型”，再在课程页开启全局开关。新生成或调整的模块会自动核查；有资料支持的明确错误最多执行一轮自动修正与复核。疑点可勾选并确认修正文案，支持恢复修正前版本。核查失败保留已生成正文，单独提示未完成。
- **课程评分**：主动点击才调用独立核查模型，展示总分、维度分和历史，不修改课程；分数不等于事实正确率。
- **任务进度与取消**：右下角显示阶段、等待时间和动态进度条，不编造完成百分比。取消会清理本次生成结果并保留原有内容；已发送到服务商的请求仍可能计费。

学习规划在结构不合格时可能发起有界的格式修正请求，增加模型调用；其他流程的重试规则见对应功能文档。程序不会自动换用其他模型服务或账号。

### 个人知识库

“我的知识库”提供知识问答、树状目录和关联图谱。卡片可按领域、课程和主题浏览，支持手动整理主题或确认 AI 归类建议；图谱可拖动、缩放与筛选，单击节点聚焦关联，双击卡片节点打开正文。

知识问答先在本机检索相关卡片，再将少量相关原文交给模型并列出引用；没有找到资料时明确提示不足。卡片以独立 Markdown 文件保存，支持编辑、导出和删除。

## 模型与可选服务

桌面版统一在“设置与数据”配置，各项独立保存、立即生效，不需要 `.env`。

| 设置项 | 用途 |
| --- | --- |
| 课程生成与答疑 | 学习规划、课程正文、练习、答疑及知识卡片 |
| 事实核查模型 | 自动质量审查与课程评分，须使用与生成模型不同的模型 |
| 课程配图 | 独立图片服务；在线搜图另行启用，百炼搜图沿用文字模型配置 |
| AI 朗读 | 独立语音服务、角色音色及缓存 |

文字服务支持 **Ollama、LM Studio、vLLM、DeepSeek、通义千问／百炼、自定义 Chat Completions 兼容接口**。填写服务实际提供的模型 ID；根地址不包含 `/chat/completions` 或 `/api/chat`。

- “仅使用本机”只允许回环地址；云端或局域网服务需关闭此项。本机模型须先自行安装、加载并启动服务。
- 保存配置不会自动调用模型。连接检查仅验证固定短提示的调用与输出，不能替代正式生成验证；文字连接检查可能计费。
- 已有 Key 留空保留，填新值替换，“清除”后保存才删除。密钥不会回显，也不会自动跨服务或地址复用。
- 生成、核查、搜索、配图和语音可能分别计费；启用可选功能前请确认对应服务能力与权限。

服务地址、Qwen 思考设置、图片协议、朗读缓存及 Web 环境变量见 [模型配置指南](docs/model-configuration.md)。

## 数据、备份与课程分享

桌面版默认数据目录为 `%APPDATA%\Learnflow\data\`；以“设置与数据 → 打开本地数据目录”显示的位置为准。

| 方式 | 包含内容 | 恢复／接收后的行为 |
| --- | --- | --- |
| 完整学习 JSON | 课程、导入资料文字、卡片、笔记、成绩、聊天、阅读位置、历史及配图；不含模型配置、Key、朗读音频 | 经确认后替换当前学习数据，导入前创建 SQLite 快照 |
| 课程包 `.learnflow-course.json` | 单条路线、已生成正文、题目与解析、配图、引用及绑定资料的全部提取文字 | 新增独立副本，进度从零开始；不覆盖已有课程 |
| Wiki Markdown | 知识卡片正文与元数据 | 用于阅读和外部编辑，不替代完整学习备份 |
| 整个数据目录 | 数据库、卡片文件、模型配置、配图、朗读缓存等 | 关闭应用后复制；加密密钥不保证可跨电脑或系统用户恢复 |

课程包不包含个人卡片、批注、心得、聊天、成绩、学习位置、需求问卷或密钥。导出前会提示包含导入资料的文字，请确认这些内容可以分享；接收方无需 Key 即可阅读，继续生成使用自己的模型配置。[课程分享说明](docs/course-sharing.md)

主要存储位置：

```text
learning.sqlite                  课程、资料文字、成绩、笔记、聊天与阅读位置
knowledge/cards/<主题>/<ID>.md     独立 Markdown 知识卡片
knowledge/catalog.json           从卡片派生的知识目录
images/                          本机课程配图
speech-cache.sqlite、audio/       朗读缓存索引与音频
settings.json、*-settings.json 等  模型参数与系统加密后的密钥
backups/                         迁移或备份导入前创建的 SQLite 快照
```

首次遇到旧 JSON 或旧版数据库时会校验并迁移，保留相应原文件或快照。应用外修改卡片后请重启再继续编辑，避免覆盖外部变更。不要在应用运行时只复制 `learning.sqlite` 作为完整备份。

软件没有云同步或遥测。导入、预览、已有内容阅读及本地检索不调用模型；使用云端模型时，当前任务所需的目标、课程、资料片段或笔记会发送到所配置的服务。

## 开发、构建与验证

### Web 开发模式

先安装依赖；需要模型时，参考 [.env.example](.env.example) 创建或编辑 `.env`，然后启动：

```powershell
npm run dev
```

打开 `http://localhost:3000`。服务仅监听 `127.0.0.1`；`.env` 仅用于 Web 模式，修改后需重启服务。浏览器学习数据保存在 localStorage，与桌面版独立。Web 用于基础流程和前端开发，不包含全部桌面功能。

### Windows x64 打包

```powershell
npm run desktop:pack
npm run desktop:build
```

前者生成解包目录，后者生成安装 EXE。需要同时生成安装版和免安装 ZIP 时执行：

```powershell
npx electron-builder --win nsis zip --x64 --publish never
```

默认输出至 `release/`。构建需要下载相关工具，当前未配置代码签名；源码、测试版与已发布安装包应分别确认版本。

### 自动化验证

```powershell
npm test
node desktop/start.cjs --smoke-test --materials-only
node desktop/start.cjs --smoke-test --ui-only
```

受限环境若因子进程权限无法运行 `npm test`，可改用 `node --test --test-isolation=none`。桌面回归使用 `.desktop-test/` 中的隔离数据和模拟模型，不消耗真实 Key。

其他专项参数：`--planning-only`、`--plan-adjust-only`、`--categories-only`、`--resume-only`、`--quiz-only`、`--sources-only`、`--facts-only`、`--quality-only`、`--sharing-only`、`--settings-only`、`--cancel-only`，均与 `--smoke-test` 一起使用。付费诊断脚本需显式授权，不属于默认自动化测试。

## 常见问题

| 问题 | 优先检查 |
| --- | --- |
| 最新功能没有出现 | 是否启动了当前源码测试版；已有安装包需重新构建 |
| 自定义模型连不上 | 模型服务是否已启动、模型 ID 与根地址是否准确、是否误开“仅使用本机” |
| 输出截断或 JSON 不合格 | 输出上限、超时、JSON 格式支持；Qwen 兼容服务可检查模型思考设置 |
| 资料导入失败 | 文件类型、大小、文字总量、UTF-8 编码；扫描 PDF 先 OCR，`.doc` 转为 `.docx` |
| 联网生成提示无可读正文 | 页面可能拒绝访问、需要登录／脚本或不支持读取；核对来源和模块目标后手动重试 |
| 正文已生成，但核查失败 | 正文仍保留；检查独立核查模型配置，再重试核查，无需重复生成正文 |
| 图片或语音已生成但下载失败 | 核对可信下载域名，保存设置后“仅重试下载”，避免重复生成计费 |
| 备份里没有朗读音频 | JSON 和课程包不含音频，需要关闭应用后备份整个数据目录 |

## 当前边界

- 资料与 Wiki 使用本地关键词检索，尚未提供向量语义检索；原文引用不等于事实核验。
- 没有代码沙箱、外部实践作业自动验收、自由作答自动评分或间隔复习算法。
- 已保存内容可离线阅读；生成新内容需要可用的本机模型或云端服务。
- 无登录、多用户协作或云同步；桌面内部服务仅用于本机访问。
