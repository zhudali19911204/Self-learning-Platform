# 知行 Learnflow

一个中文、自助式 AI 学习工具：目标 → 路线 → 课程 → 练习与 AI 答疑 → 个人 Wiki。提供 Windows 桌面版，也保留 Web 开发模式。

## Windows 桌面版

当前源码版本为 `1.1.7`，对应 Git 标签 `V-1.1.7`。打包后运行 `release/Learnflow-Setup-1.1.7.exe` 安装。也可直接运行 `release/win-unpacked/Learnflow.exe`（需保留同目录的其他文件，不能只拷贝 exe）。安装后从桌面“知行 Learnflow”快捷方式打开，无需安装 Node.js，也不用手动启动 Web 服务。旧版 `0.1.0` 安装包不包含新增的 SQLite 存储；请重新打包或用开发测试版体验最新功能。

源码启动及打包：

```powershell
npm install
npm run desktop
```

调试时可直接启动独立的开发测试版（不打包）：

```powershell
npm run desktop:dev
```

开发测试版会打开模型设置页，使用项目中的 `.desktop-dev/data/` 保存数据，与已安装版本和自动化测试数据分开，可以同时运行。首次运行新版时，如果存在旧 `learning.json`，会校验并导入 SQLite；原 JSON 和 `.bak` 原样保留。已有 Wiki 卡片随后迁移为 `knowledge/cards/` 下的独立 Markdown 文件，并按卡片主题分入子目录。它不会自动导入正式版模型配置或学习记录，需要在测试版填写配置，或手动导入学习备份。源码新增功能会先出现在开发测试版；已有安装包不会自动更新。

```powershell
npm run desktop:build
```

`desktop:build` 生成 Windows x64 安装包；`desktop:pack` 只生成解包目录。开发/构建需要 Node.js 22.16 或更高版本。首次安装依赖和打包需要联网下载 Electron、NSIS 等工具；应用运行时不需要这些构建工具。当前安装包未做代码签名。

### 在应用内配置模型

进入左侧“设置与数据”，LLM 文字、图片生成、语音生成集中在同一页的三张配置卡片（窄窗口自动纵向排列），不需要切换子页面。填写对应模型名称、地址与 API Key，然后保存该卡片。高级选项（JSON 模式、尺寸、音色、语速、超时、下载域名等）按需展开。保存一张卡片不会丢失其他卡片未保存的填写内容；未保存内容仅留在本次运行的内存中，不写入文件。配置立即生效，不需要 `.env`，也不需要重启。桌面版不会自动读取系统环境变量或 Web 版 `.env`，以避免误用其他项目的云端配置。

文字模型按模型服务分别记住配置（Ollama、LM Studio、vLLM、DeepSeek、通义千问、自定义兼容接口），图片模型按接口协议分别记住配置（通用兼容、百炼原生）。切回已保存的服务或协议，自动恢复模型名称、地址、本机限制、高级参数及密钥是否已保存；点击该卡片“保存”后才切换实际使用的配置，选择本身不联网、不测试、不生成。未保存的参数及新填密钥仅按服务暂存在当前窗口的内存中，不跨服务复制；保存成功后会清除该服务的已保存输入草稿。每个服务/协议保留最近一次成功保存的配置，目前不是同一服务下多套具名配置。

各服务存档位于原 `settings.json` / `image-settings.json` 的 `profiles` 字段中，API Key 使用系统安全存储分别加密；页面只收到公开参数和 `hasApiKey` 状态，不接收明文或密钥密文。当前单份旧配置会作为第一份存档载入内存，初始化不改写旧文件，首次成功保存时才写入新字段并保留 `.bak`。切回原服务可复用该服务及原地址对应的密钥；修改地址仍不会将旧密钥发送到新地址，必须按需重新填写。损坏或无法解密的存档不会被默认值覆盖，保存失败也不会改变当前服务。旧版本已经覆盖且不在现有文件中的历史配置不会凭空恢复，需要首次重新填写保存。

- 默认启用“仅使用本机模型”：只允许 `localhost`、`127.0.0.1`、`::1`，阻止云端和局域网地址。
- 本地使用：先在 Ollama、LM Studio 或 vLLM 安装/加载模型并启动模型服务，再填写实际模型 ID。软件不捆绑模型权重，也不会自动安装或启动模型服务。
- 云端使用：关闭“仅使用本机模型”，选择 DeepSeek 或通义千问，直接填入 API Key。使用云端时，相关课程和笔记会发送给服务商。
- API 地址留空时使用服务预设；自定义兼容服务必须填写。地址不含末尾的 `/chat/completions` 或 `/api/chat`。
- 保存后点击“测试已保存的模型连接”。改动未保存时不能测试；连接测试仅发送固定短提示，云端按服务商规则计费。
- 如果提示远端地址与“仅使用本机模型”冲突，可点击“允许远端连接并保存”，明确允许后应用会取消仅本机选项并保存当前表单。也可保留此选项，将接口地址改为本机服务；冲突时不会改动已保存的配置。
- API Key 不再有操作下拉菜单：有就直接填，没有可留空（已启用的云端服务仍需满足服务商鉴权要求）。填写新密钥即替换；已有密钥不回显，留空保留。如需删除，点击输入框旁“清除”后保存，可在保存前取消清除；已启用的云端服务可能需要先关闭启用开关。
- 不跨服务或地址沿用密钥；切回已有存档且地址未变时，可留空保留该服务原有密钥。新服务或新地址需按需填写自己的密钥。

示例课程、练习、已有 Wiki 的阅读和编辑都可以离线使用。生成新内容需要可用的本地模型服务，或联网使用云端模型。

### 接入课程图片生成模型

在“设置与数据”同页的“图片生成模型”卡片中启用课程配图，再填写文生图模型 ID、接口根地址与独立 API Key，保存后立即生效。默认关闭配图、开启仅本机模式；不会沿用文字模型的密钥，也不读取 `.env`。

- 选择通用兼容协议时，根地址填写到版本路径，例如 `http://127.0.0.1:8001/v1`；应用自动追加 `/images/generations`，不要填完整生成路径。本地必须已经运行提供文生图接口的服务；普通聊天模型服务不一定具备图片生成能力，软件不会安装图片模型或启动 GPU 推理服务。
- 云端须明确关闭“仅本机图片服务”，并使用 HTTPS。图片接口协议可选“通用兼容接口”或“阿里百炼原生接口”；旧配置默认继续使用通用兼容协议，不自动改地址或发送新请求。ComfyUI 工作流、百炼旧版异步任务接口暂不支持。
- 通用协议每次发送 `model`、`prompt`、`n: 1`、`size`。尺寸为 `宽x高`，默认 `1024x1024`，仍须符合所选模型的支持范围。返回格式选“自动”时不传 `response_format`；也可明确选择 `b64_json` 或 `url`。支持 `data[0].b64_json` 和 `data[0].url`，不支持异步任务轮询或流式图片结果。协议参考：[vLLM-Omni 文生图服务示例](https://docs.vllm.ai/projects/vllm-omni/en/latest/user_guide/examples/online_serving/text_to_image/)。
- “检查已保存的服务”只请求模型列表，不会生成图片；普通百炼原生模式在 `/api/v1/models` 按模型 ID 查询并解析 `output.models`，Token Plan 查询同域名的 `/compatible-mode/v1/models` 并解析 `data[].id`。它只能证明模型列表接口可访问，不能保证生成权限、文生图能力或实际计费。不支持模型列表的服务可直接在课程中手动验证生成。
- Base64 结果直接保存本地。URL 结果只允许从配置接口的同源地址下载；如果服务返回 CDN URL，需要在“额外允许的图片下载域名”填写服务商可信的精确域名，以英文逗号分隔。不自动访问未知地址，不跟随重定向，下载不携带模型密钥或 Cookie。

#### 百炼原生配置示例

在同页“图片生成模型”卡片中选择：

- 协议：阿里百炼原生接口。
- 模型：`wan2.7-image-pro`，也支持 `wan2.7-image`、`qwen-image-3.0-pro`、`qwen-image-3.0`。
- 北京普通百炼根地址：`https://dashscope.aliyuncs.com/api/v1`；也可填控制台提供的 `https://<业务空间ID>.cn-beijing.maas.aliyuncs.com/api/v1`。新加坡使用控制台的同地域地址和密钥。只填域名时会补齐 `/api/v1`；填写百炼官方域名的 `/compatible-mode/v1` 地址时，原生模式保存为同域名的 `/api/v1`，并在界面明确提示。完整生成路径仍不可填，未知服务商的兼容地址不会被猜测转换。
- 关闭“仅本机图片服务”，普通百炼地址填写普通百炼 API Key；Token Plan 地址填写其对应的套餐密钥，不混用。切回已有协议存档且地址未变时，可留空保留其已保存图片密钥；新协议或新地址需按需填写密钥，不会沿用聊天模型密钥或把旧密钥转发到其他服务。
- 尺寸：先用 `1024x1024`，发送时自动转为 `1024*1024`。万相还可填 `1K` / `2K`，pro 支持 `4K`；千问 3.0 填宽x高。应用会预检对应模型的像素范围和宽高比。原生模式固定自动返回格式，不传 `response_format`。

原生请求采用 `input.messages[].content[].text` 和 `parameters: { n: 1, size }`，调用 `/services/aigc/multimodal-generation/generation`，从 `output.choices[].message.content[].image` 取回 URL 并立即保存到本机。仅原生模式且根地址为百炼官方域名时，内置允许已核实的 10 个地域图片结果域名和 14 个加速存储域名（含 Token Plan）；其他 CDN 或代理服务仍需显式填写可信域名。本机模式不会访问远端 CDN，远端下载仅接受 HTTPS 默认端口，不允许通配符、任意 OSS 桶或全部 `aliyuncs.com` 域名。参考：[万相原生同步接口](https://help.aliyun.com/zh/model-studio/wan-image-generation-and-editing-api-reference)、[千问图片原生同步接口](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)。

遇到“图片下载地址不在允许范围内”，先不要重启或重新生成：在配图面板点“打开图片设置”，将报错中的完整域名追加到“额外允许的图片下载域名”（已有域名用英文逗号分隔），保留密钥、关闭仅本机模式并保存；回到原内容块再次打开配图面板，点“仅重试下载”。仅修改下载域名不会清除当前待下载链接。

配置保存与服务权限分开处理：软件不再因 Token Plan 域名拒绝保存。可填写 `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`，原生模式会将路径调整为同域名的 `/api/v1`；不会更换域名、切换到普通按量计费服务或自动替换密钥。保存不发起网络请求，课程仍须手动确认才生成图片。原生路径参考 [Token Plan 多模态生成文档](https://help.aliyun.com/zh/model-studio/token-plan-multimodal-gen)。

允许保存仅表示配置符合本地格式要求，不代表套餐允许当前使用方式或生成权限已验证。Token Plan 个人套餐官方规则限制其通过编程／智能体工具的扩展机制交互使用，并限制自定义应用后端调用；界面保留使用范围提醒，请确认服务商是否允许你的实际使用场景。参见 [Token Plan 使用范围](https://help.aliyun.com/zh/model-studio/token-plan-personal-overview)。失败时显示具体保存原因或预设服务错误说明、已知错误码及合法请求 ID，不回显服务商原始报错中的密钥、提示词或链接；不自动重试、不回退到其他协议，不轮询意外返回的异步任务。

开启后，新生成的内容块讲解、案例与动手实践会让文字模型判断是否需要图片，有需要才附带配图建议；不为装饰硬凑配图。已有内容可点击右上角“AI 配图建议”。打开面板后，用户可修改提示词和中文图注，最后点击“确认生成图片（可能计费）”才调用图片模型，每次一张，不自动重试。文字模型未连接时，也可直接填写自己的图片提示词。配图分析会发送当前模块正文给文字模型；图片生成仅发送确认的提示词给图片服务。

配图面板有“AI 提示词生成”和“在线找图”两种方式，在线找图默认使用**百炼文搜图**，Commons 作为可选图库保留。先在“设置与数据”启用“百炼网页搜图”，沿用当前文字模型的地址、模型及密钥，不需要 Tavily 或另一套搜索 Key。保存开关不发起搜索，也不改变原模型配置；开关单独保存于 `web-search-settings.json`，只记录是否启用，不复制密钥。需使用支持文搜图的百炼模型（如 `qwen3.8-max`）及官方 `/compatible-mode/v1` 根地址，Token Plan 用户仍须核对官方对自定义应用后端的使用限制。

在“在线找图 → 全网图片 · 百炼”中，手动搜索发送下方需求；“AI 自动找图”将当前模块的标题、目标及最多 1000 字正文摘要发送给当前百炼模型。应用调用同源 `/responses`，使用 `web_search_image` 工具，并强制要求实际工具调用；不抓取普通聊天回答里自行编造的图片链接。使用官方流式响应，对 Qwen3.8 使用 `reasoning.effort=low` 降低不必要的思考耗时，输出上限为 2500 Token；不自动切换模型、不切换到其他计费账号、不自动重试。搜索可能消耗套餐 Credits 或模型及工具费用。图片候选最多展示 8 张，附带模型推荐说明；许可默认标记“授权未确认”，不会将搜索到的图片视为免费或可商用。若工具没有提供来源页面，明确提示仅有原图链接，不编造出处。

图片预览会从来源网站获取图片并在主进程缩小为本地预览；网页无法直接加载第三方图片或跟踪链接。只允许公共 HTTPS 图片，先验证 DNS，再锁定实际连接地址，禁止访问本机、局域网、云实例元数据和保留地址；不跟随重定向、不附带模型密钥或 Cookie，也不绕过登录、防盗链或访问限制。未能预览的候选仍显示标题及链接，可用系统浏览器查看。搜索不自动替换课程配图；需确认具备当前用途的使用权限，再点击下载保存。确认下载只重用当前运行内存中的候选标识，不再次调用模型；候选保留 30 分钟，改变模型、地址或密钥后失效。本地图片继续沿用 12 MB / 4096 像素校验和完整备份机制。协议依据：[百炼文搜图](https://help.aliyun.com/zh/model-studio/web-search-image)、[Responses API](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-responses)。

Commons 模式不依赖图片模型或图片 API Key；可以手动输入关键词，也可以在文字模型可用时点“AI 自动找图”，让文字模型根据模块内容提取检索词。手动搜索仅发送关键词到 Wikimedia；AI 自动找图先调用当前文字模型，再把关键词发送给 Wikimedia。其许可仍应在原始页面核对。

网络资料与 AI 生成图片分别标注。网络资料保存图注、来源页面、作者、许可名称和本地图片标识，沿用相同的课程版本、完整备份及本地图片校验机制。Wikimedia 元数据也可能不完整或发生变化，请在原始页面核对许可；若下载前许可状态变化，应用会要求重新搜索。Commons 图库只接受 Wikimedia 固定媒体域名的 HTTPS PNG、JPEG 或 WebP，不跟随重定向，不附带模型密钥，图片仍受 12 MB / 4096 像素限制。图片检索接口依据 [MediaWiki Search API](https://www.mediawiki.org/wiki/API:Search/en) 与 [Imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo/en)。

网页图片下载将默认 CA 与系统信任证书合并，仅用于这些 HTTPS 请求；保留证书链及主机名验证，不设置跳过证书校验，不更改系统或其他模型请求的信任配置。若证书、格式、尺寸或站点访问限制阻止下载，保留候选并显示原因，不自动重新搜索。

`test-support/web-images-live.cjs` 是独立的真实搜图诊断入口，必须显式传入 `--confirm-paid`；单次最多 1 次 Responses 请求，不由自动测试运行。`--check-only` 只 GET 模型列表，不搜索或生成。诊断读取开发测试版的加密文字模型配置，输出只包含模型、请求次数、候选摘要与结果，不回显密钥或原始上游错误；不修改账号、模型配置或课程。

图片和图注显示在对应讲解、案例或实践任务正文之后；生成图片标注“AI 生成教学示意”，网络图片标注来源与许可状态。图片模型可能误画结构、文字或数值，配图不能代替正文、精确公式和数据验证；优先使用无文字、少元素的场景与直观类比。先前移除的流程图/架构图/数据图表代码绘制功能仍然关闭。不为旧固定结构课程、答疑或 Wiki 自动添加配图，不改写已保存的课程正文。

生成失败保留正文、原配图和输入要求；生成与下载分别使用设置中的超时时间（例如各 180 秒），生成耗时不会提前用尽图片下载的时间。如果生成请求超时，服务端可能仍在生成，请先查服务商记录，避免重复计费。如果服务已返回图片 URL，但下载或本地保存失败，面板显示下载域名（不显示完整签名链接），切换为“仅重试下载（不重新生成）”。可先打开图片设置，核对后填写可信的精确下载域名，再回到原内容块重新打开配图面板，仅下载已有结果；每次都重新校验当前下载权限和图片内容，不自动重试、不调用生成接口。

待下载结果仅存在桌面主进程内存中，最多保留 20 个、每个 30 分钟，不写入学习数据、日志或备份，关闭应用后失效。仅修改下载域名不丢失待下载结果；更改服务、模型或对应正文／配图会使它失效，避免错配与过期覆盖。已有待下载结果时，即使重复点击生成也不会再调用模型；必须明确确认“放弃此结果，重新生成（可能计费）”，才可重新提交生成。旧版失败时未保留的链接无法从本地恢复，应先查看服务商记录。

同一内容块禁止并发生成或下载；返回时再次检查内容版本，过期结果不覆盖新讲解。重新生成讲解会把该讲解的配图一起放入历史版本，新正文不沿用旧图；“恢复上一版”会恢复对应配图。仅调整图片会替换当前配图，不另外建立图片版本历史。

图片最大 12 MB、最长边 4096 像素，仅接受经校验的 PNG、JPEG、静态 WebP。图片二进制保存到本机 `images/<SHA-256>.img`（扩展名不改变实际图片格式），相同内容自动去重；SQLite 仅存图片标识、提示词、图注、模型名和时间，不将图片 Base64 写进每块正文。完整 JSON 导出和删除路线前的备份会嵌入当前及讲解历史引用的图片，导入时先校验并恢复图片，再事务替换学习记录。备份不含模型配置或密钥；当前 JSON 备份上限约 250 MB，大量图片时应在应用关闭后保留整个本地数据目录。删除路线或替换配图暂不自动清理图片文件，避免使旧备份失去图片；不要手动删除仍被引用的文件。

### AI 听力朗读

桌面版支持 `qwen-audio-3.0-tts-plus`，语音配置独立于文字和图片模型。在“设置与数据”同页的“语音生成模型”卡片中启用，直接填写对应账号的 API Key，并关闭“仅本机语音服务”。音色、语速等在“高级设置”中调整。可填用户指定的 `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；保存时只将路径调整为同域名 `/api/v1`，实际请求 `/services/audio/tts/SpeechSynthesizer`，不切换普通百炼服务或模型。协议依据：[Token Plan 多模态生成](https://help.aliyun.com/zh/model-studio/token-plan-multimodal-gen)。套餐是否允许当前使用方式仍须核对服务商规则。

默认不启用，也不自动沿用文字或图片密钥；只有用户明确授权复用同一账号密钥时，才将它单独加密保存为语音配置。本次开发已按用户授权，用图片账号的同一密钥配置开发测试版；不改变正式版配置。“检查已保存的语音服务”只查询模型列表，不生成试听，不能代替真实合成权限验证。

使用方式：

1. 在课程阅读页右侧点击“AI 答疑”下方的“AI 朗读”。可先选中课程中的英文；未选中时会预填当前阅读附近的已生成内容块，旧固定结构课程使用其示例材料。也可在弹窗中粘贴材料；不会自动读取外部文档。
2. 核对材料和角色音色，再点“预览角色与缓存”。自动提取优先使用听力文字围栏，不是模型分析，不调用付费服务；提取可能不准确，请人工确认。材料最多 8000 字，按角色和长度拆为最多 16 段，每段最多 1500 字。`Sarah:` 等姓名只用于分配音色，不被朗读。
3. 点“确认生成 N 段 AI 朗读”才合成尚未缓存的片段；每段一次请求，可能计费。失败停止后续片段，不自动重试，也不切换服务；已经生成并下载的片段保留。
4. 点击播放或单段重听，支持暂停、停止、0.75× / 1× / 1.25× / 1.5× 播放速度。重复播放、预览和重新打开弹窗均复用缓存，不重新合成。音频不会生成后自动播放。

默认音色 `longanlingxin`（女声）与 `longanlufeng`（男声）支持中英，也可填写该模型支持的基础或自建音色 ID；角色按出现次序交替分配默认音色，用户可分别修改，不猜测角色性别。默认音色不保证特定美式或英式口音，须实际试听；不要混用其他模型的 Jennifer、Aiden 音色。参考：[Qwen Audio 音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。

请求仅发送确认的原文、音色和合成参数，不发送全课程、笔记或问答历史。第一版请求 24 kHz PCM WAV，兼容直接返回二进制或 JSON `output.audio.url`。真实测试发现该服务可能保留流式 WAV 长度占位值，应用只修复已核实的特定文件头，随后严格校验格式、采样帧和大小，不放宽对任意损坏文件的校验。音频最大 20 MB，通过桌面本地服务播放，不从页面直接访问云端。

音频下载沿用精确域名授权：官方地域和加速结果域名内置允许，其他可信域名须手动添加。官方签名 HTTP 下载地址只在域名可信时升级 HTTPS，不回退 HTTP、不携带模型密钥或 Cookie，不跟随重定向。下载失败且有已生成链接时，只能先“仅重试下载”，不再次合成、不顺便生成剩余片段。待下载链接仅在当前运行内存中保留 30 分钟，关闭后失效；不要为下载失败反复点击新生成。

缓存按服务、模型、文本、音色、语言、合成语速建立索引，修改这些参数会使用新缓存，旧文件保留。缓存不改写课程内容；现阶段不随课程删除自动清理，也不将音频嵌入学习 JSON 备份。若需要保留全部音频，请关闭应用后备份整个数据目录。现阶段不支持声音克隆创建、跟读评分、实时对话或把音频嵌入 Wiki / Markdown 导出。

自动验证：`node --test --test-isolation=none`，以及 `node desktop/start.cjs --smoke-test`；后者使用隔离的 `.desktop-test/` 和本机模拟服务，不会调用真实账号。`test-support/speech-live.cjs` 是显式的真实诊断入口，不由测试套件调用；只有收到付费授权才能运行，单次最多一次合成。真实测试产生的试听文件存于 `.desktop-test/tts-live/`，开发测试版另存正常的本地缓存。

### 从模糊需求到定制路线

“开启新的学习 / 新建学习路线”采用三个交互步骤：

1. 描述需求：可以只说兴趣或难题，不必先给出完整目标；同时选择基础、每天时间和周期。
2. 澄清方向：AI 先分析用户已明确的事实和真正影响课程路线的未知，再按缺口逐项生成问卷。具体场景与成果已经明确时询问 2–3 题；只给兴趣、学科或宽泛方向时询问 4–6 题；模型返回的题数与分析结果不一致会要求修正一次，不会截断或硬凑成三题。支持单选、多选、自由补充和“还不确定，请 AI 推荐”，不会默认替用户选择。每题至少选择一项或填写自己的想法。可点“重新梳理问题”重新分析同一需求；若 AI 问得太少，可点“深入澄清（4–6 题）”主动要求更深入。成功后新问卷会替换原问卷和回答，失败时原问卷保留。
3. 确认并规划：查看 AI 初步理解和自己的回答，补充成果要求、排除范围或工具限制，再生成学习路线。可返回修改，关闭问卷后本次运行中仍保留草稿；修改原始需求或时间安排后会重新生成问题。应用重启不会保留未完成的问卷。

规划要求以可验收的成果倒推课程，明确先修关系、贴合所选场景的实践和阶段里程碑；需求超过时间预算时说明取舍，不承诺短期精通。系统校验课程数量、字段、总时长及重复标题/目标；这些检查不能替代对教学内容的人工判断，实际质量仍取决于模型。问卷现在分为“分析需求缺口”和“生成针对性问题”两次模型调用，各阶段结构不合格时最多自动修正一次，因此云端可能产生额外费用；失败保留当前输入和已有问卷，不保存半成品路线。

确认后的需求保存为路线的 `learningBrief`，原始 `goal` 不被覆盖；在路线页可展开“查看定制需求与回答”。桌面版随路线写入 SQLite 的现有 `meta` 表，不升级表结构；Web 版随浏览器学习记录保存。完整导出和导入包含这些需求；桌面版删除路线时会从历史备份中移除其需求。之后生成大纲、正文及重新讲解时会继续参考它们，已有路线与课程不被自动改写。使用远端模型时，原始需求、问卷回答和补充说明会发送到已配置的模型服务，请勿填写敏感信息。

新生成的 AI 课程采用分步模式：先生成本课大纲，再按需点击每个内容块单独生成讲解、示例、实践、练习或总结；还可以在课程末尾添加自定义内容块。已生成的内容块立即单独保存，未生成的块只保存标题和目标。旧版固定结构课程继续原样阅读、练习，无需重生成。

生成新课程大纲时，应用会提供它在整条学习路线中的位置，减少跨课重复；生成内容块时，会提供本课目标、学习者基础、附近的大纲，以及最多 3 个先前内容块的节选，让新讲解承接前文。讲解、示例、实践、测验和总结采用不同的教学要求；上下文会截短以控制请求体积。此改进只影响之后生成的内容，不会自动覆盖你已保存的课程。

新版内容块课程中，相邻的讲解与案例显示在同一个学习单元里，以“知识讲解”和“配套案例”明确区分，仍然按块单独生成和保存。新大纲会要求按“讲解 → 配套案例”的顺序安排模块。点击“换个讲法”或“换个例子”，填写哪里不清楚、希望如何解释，即可只重新生成当前模块；模型返回并成功保存后才替换原文，失败保留原文和输入要求。每块保留最近 10 个旧版本，可以逐次“恢复上一版”；历史也包含在学习备份中。其他模块、练习成绩、心得和已保存的 Wiki 不会自动改写。此功能只针对新版内容块课程，不转换旧版固定结构课程。

动手实践保留“AI 配图建议”和“换个任务”；朗读入口统一移到课程右侧的“AI 答疑”下方。将实践块滚动到可见位置后点击“AI 朗读”，会优先预填当前块的听力材料，仍需在弹窗中核对。配图入口需启用图片模型。任务反馈可调整场景、材料、步骤和难度，保持原学习目标，写明完成标准和自查提示，不直接给出完整答案。更换任务保留最近 10 个旧版本和对应旧配图，支持“恢复上一版”；失败保留原任务。其他模块、成绩、笔记和 Wiki 不受影响，旧音频缓存保留，但不会自动套用到新材料。不需要数据库迁移；旧固定结构实践不进行转换。

新版讲解、案例及其他文本块使用 Markdown 文档排版：模块标题与正文小节分级显示，支持重点加粗、编号/项目列表、引用提示、表格、行内代码与代码围栏。生成要求也同步使用 Markdown，但模型接口的根输出仍为 JSON，`text` 保存原始 Markdown，不改变 SQLite 表结构。已有纯文本仍可阅读，不会自动猜测标题或改写原文；可点击“换个讲法 / 换个例子 / 换个任务 → 仅优化排版 → 按要求重新生成”，把当前内容整理成 Markdown，并保留上一版。排版优化仍由模型生成，涉及数值或代码时应复核。

暂时移除流程图、架构图和数据图表的生成与专用绘制功能。课程讲解、案例、AI 答疑和 Wiki 使用文字、列表、步骤与普通 Markdown 表格说明关系和数据；标题、重点加粗及程序代码围栏等排版仍然保留。已有课程或卡片中的 `flow`、`architecture`、`chart` 围栏显示为普通代码块，源文、历史版本和备份保持不变，不进行数据删除或迁移。

Markdown 解析和安全过滤分别使用随应用本地安装的 [Marked](https://marked.js.org/) 和 [DOMPurify](https://github.com/cure53/DOMPurify)，不加载 CDN。原始 HTML 仅作为文字显示，不执行脚本；正文不加载远程图片，引用链接显示为名称与地址而不直接跳转，避免打断学习或自动向外部站点发送请求。

AI 答疑、知识库问答、知识卡片正文和课程总结均使用同一套 Markdown 排版。新生成的答疑和 Wiki 也会要求模型在原有 JSON 字符串字段内输出 Markdown，引用卡片仍单独展示。知识卡片默认打开“阅读”视图，阅读内容区域只显示标题和 Markdown 正文，不额外展示 YAML 中的摘要、适用或不适用场景；这些元数据仍保留在编辑页、文件和 AI 检索中。可切换“编辑 Markdown”；切换不会清空当前草稿，阅读可预览未保存内容，但编辑后仍须点击“保存修改”。桌面版每张卡片另存为 YAML 头部加 Markdown 正文的文件；“导出 Markdown”会导出该文件当前已保存的源文。渲染后的 HTML 不写入学习数据库，也不改写已有正文。旧版“学习笔记”入口已移除，但已保存的学习心得仍保留在本地数据与备份中。

“学习路线”页面会根据路线标题、目标和课程标签，在本机自动分组（例如 AI 与大模型、数据分析、开发工具），不调用模型也不修改原课程。选中一条路线后可点击“删除这条路线”；删除会连同其课程正文、进度、答疑和 Wiki 卡片一起移除，至少保留一条路线。桌面版不会再生成删除前备份；会从旧 JSON 备份中移除该路线（保留其他路线），删除包含该路线的旧版 SQLite 快照，并清理该路线独有的配图及已关联语音。旧版未记录课程归属的语音缓存无法安全识别，会保留。Web 版仍会在浏览器本地留存删除前记录，并提供“恢复最近删除”。

规划路线时，模型必须返回 3–12 节课程、完整字段，且总课时不超过计划投入时间。应用会根据时间预算给出建议课程数量和多课程结构示例，明确学习周期不等于课程数量。如果首次结果结构不合格，应用会携带具体原因与限长失败草稿自动再调用模型一次，要求拆分过少的课程或合并过多的主题；这可能产生第二次模型调用费用。仍不合格时会区分“缺少课程数组”与“数量不符”，显示实际返回数量，不会保存半成品路线。这些提示说明模型输出不合格，不代表模型无法连接。

学习时可点击课程正文右侧常驻的“AI 答疑”按钮，直接进入当前课程的答疑页并定位到提问框；桌面版的“AI 朗读”按钮位于其下方，窄屏时两个入口固定在右下角。也可以使用原有“AI 答疑”标签。答疑页的“返回学习内容”按钮以及“学习内容”标签会恢复进入答疑前的页面位置，切换课程时则重新从课程开头阅读。AI 会参考本课内容和最近 12 条对话；每节课保留最近 20 条问答消息，桌面版保存在本机学习记录中，Web 版保存在当前浏览器。没有可用模型时，课程仍可阅读和练习，但无法进行 AI 答疑。云端模型答疑会将本课内容、问题和最近对话发送给已配置的服务商。

### 本地数据与备份

Windows 默认保存位置为 `%APPDATA%/Learnflow/data/`，可在设置页点击“打开本地数据目录”查看实际位置。

- `learning.sqlite`：桌面学习数据库。课程正文按课读取，大纲和内容块分别存储、按块写入；成绩、心得和答疑也保存在这里。Wiki 卡片在 SQLite 中保留兼容索引和正文副本，以支持现有界面及 JSON 备份；普通卡片编辑以 Markdown 文件为准。
- `knowledge/cards/<主题>/<卡片ID>.md`：每张知识卡片的 YAML 元数据和 Markdown 正文。主题支持 `编程/Python` 这样的分级；目录名经过安全规范化，卡片 ID 文件名保持不变。升级时先读取并校验原 Markdown，再通过临时目录原子替换；旧卡片保留正文、YAML 扩展字段和来源，原来未分类的卡片进入“未分类”目录。
- `knowledge/catalog.json`：从卡片 YAML 派生的知识目录，只保存标题、摘要、主题、标签和显式关系，不复制正文；损坏或丢失时可由卡片文件重建。知识库页面有“知识问答”“树状目录”“关联图谱”三个标签页：树状目录按固定的常用领域 → 课程 → 少量主题 → 卡片展示，课程使用已有课程 ID 固定归属；旧卡片会按已有主题、标签自动归组，单张零散主题并入“课程要点”，不为每张卡片建立目录。每个课程旁的“管理主题”入口始终可见，可在“当前归类”中手动修改、合并主题，或者撤销本次运行中上一次整理。配置文字模型后，还可主动切换到“AI 建议”：默认仅处理未手动分类的卡片；选择“重新整理本课程”时，已有手动分类默认锁定，须逐张解锁才会送给模型。只发送选中卡片的标题、摘要和标签；生成或重新生成建议可能消耗模型额度，但打开管理界面、编辑建议或预览不调用模型。用户可逐张勾选和改写建议，确认后才保存；归类仅改动展示与检索元数据，不移动原有 Markdown 文件。搜索时也可按领域、课程和主题查找。问答在独立页面中进行；图谱用本地力导向布局展示原始主题层级、卡片归属、卡片 YAML 中的明确相关/前置/对比关系，以及用虚线标出的共同标签候选关联。图谱卡片按树状目录的顶层领域使用预设颜色；九个常用领域各有固定颜色，新增卡片不会改变已有配色，“待归类”使用灰色。图谱支持拖动节点与画布、滚轮缩放、暂停运动、刷新布局、适应画布，并可按目录、类型、状态、标签、关系筛选，查看孤立卡片或选中卡片的局部两跳关系。系统偏好减少动画时默认暂停。悬停节点可临时聚焦直接关联；点击节点可保持聚焦并打开卡片，再次点击同一节点可取消聚焦；图谱一次最多绘制 240 张卡片以保持流畅，超出时会提示，搜索或按主题缩小范围仍可查看较早卡片。图谱不会自动把候选关系写回卡片，也不会调用模型。问答不再固定发送最近 30 张，而是先在所有卡片中按领域、课程、主题及正文相关度检索，再带上显式关联的卡片，将少量相关原文交给模型；找不到时不调用模型，并明确提示资料不足。当前是本地关键词检索，不承诺语义召回。
- `knowledge/generation.json`：协调 SQLite 与卡片文件的导入／删除版本。勿单独删除；导入备份或删除课程时会据此更新卡片目录。修改 `.md` 后重启应用即可重新读取；文件格式有误时会保留原文件并拒绝静默覆盖。
- 在知识库打开卡片后，可点击“删除这张卡片”。桌面版会再次显示系统确认框；确认后只移除该卡片的 Markdown 文件、SQLite 记录和派生目录条目，不删除来源课程或其他卡片。若卡片文件在应用外修改过，删除会被拒绝，须重启后核对。Web 版确认后只更新当前浏览器记录。卡片删除无法在应用内撤销；先前导出的文件和历史备份可能仍保留旧副本。
- `learning.json`、`learning.json.bak`：升级前的旧学习数据；迁移后不用作实时数据库。删除路线时会从这些历史副本中移除对应路线；若副本只包含该路线则删除副本。
- `settings.json`：模型配置；API Key 使用 Windows 系统加密机制加密后保存，不以明文写入。
- `image-settings.json`：独立的图片模型配置及系统加密后的图片服务密钥；`.bak` 保留上次配置。默认关闭，不影响已有文字模型。
- `images/`：本地课程配图文件；正文与讲解历史只保存图片引用，读取时由桌面内部服务提供，不加载外部图片。
- `speech-settings.json`：独立语音配置及系统加密后的语音密钥，`.bak` 保存上次配置。系统加密与本机用户及应用配置目录关联，不应依赖复制此文件在另一配置目录恢复密钥。
- `speech-cache.sqlite`：朗读缓存索引及新朗读的课程关联；不保存原文、密钥或云端签名链接。损坏时保留原文件并暂停合成，不阻止打开课程，也不自动重新计费。
- `audio/<SHA-256>.wav`：经校验的本地朗读音频，内容去重，支持离线重听；缓存不包含在学习 JSON 导出中。
- `backups/`：导入 JSON 备份或从旧版 SQLite 升级结构前自动创建的 SQLite 快照。删除路线时，历史 JSON 备份会剔除该路线及其独有图片；包含该路线的旧版 SQLite 快照会整体删除，因为其结构可能不同。`settings.json.bak` 仍只保留上次设置保存前的版本。

首次迁移会先校验旧数据，再创建新数据库；迁移失败不会修改旧 JSON。知识卡片迁移前另建 SQLite 快照，生成的 Markdown 会逐张回读验证。当前卡片 YAML 包含 `id`、`title`、`description`、`topic`、可选的 `knowledge_category`、`use_when`、`avoid_when`、`aliases`、`tags`、`source_course`、`source_lesson`、`source_lessons`、`related_cards`、`prerequisites`、`contrasts`、`status`、创建及更新时间；历史卡片的适用场景和关系默认留空，不由 AI 猜测。`knowledge_category` 是手动指定的课程内主题，不改变 `topic` 所决定的磁盘位置。应用外编辑卡片后请重启再在应用中继续编辑，以免覆盖外部修改。不要在应用运行时只复制 `learning.sqlite` 作为备份，应保留整个数据目录或使用应用内“导出完整 JSON 备份”。系统加密不可用时拒绝保存密钥，可继续使用不需要密钥的本地模型。加密密钥绑定当前系统用户，不应依赖复制 `settings.json` 在另一台机器上恢复密钥。

“导出完整 JSON 备份”和“导出 Wiki Markdown”会打开系统保存对话框。完整 JSON 导出会从数据库读取全部课程，包括尚未在当前会话打开的课程，并包含当前与讲解历史引用的配图。可导入旧 Web 版导出的 Learnflow JSON；导入前会创建 SQLite 快照，再以事务替换学习数据，模型配置不受影响。学习备份不包含密钥。Web 版浏览器数据与桌面版文件彼此独立，不会自动迁移；含课程配图的新备份请在新版桌面应用导入，Web 模式不加载配图资产。

桌面窗口使用隔离和沙箱，页面没有 Node.js 权限。内置服务仅绑定回环地址、使用随机端口和会话令牌，随应用关闭；不会提供局域网服务。软件本身没有云同步或遥测。

## Web 开发模式

需要 Node.js 22.16 或更高版本。Web 服务本身没有第三方运行依赖；桌面开发需要执行 `npm install` 安装开发依赖。

```powershell
npm run dev
```

打开 http://localhost:3000。服务仅监听本机 `127.0.0.1`，请通过 `localhost` 或 `127.0.0.1` 访问。

未配置模型时，可直接体验 Python 入门示例：6 节完整课程、12 道测验题、成绩反馈、课程笔记、Wiki 卡片编辑、标签关联、关键词检索和 Markdown 导出。示例模式不把预设内容伪装成 AI 生成，不支持自定义主题生成。

## 连接真实 AI

本节 `.env` 配置仅用于 **Web 模式**。桌面版请在应用内设置相同的服务、模型和地址。

已支持国产云端模型和本地部署模型，所有调用由服务端发出。无需安装服务商 SDK。

| 接入方式 | `LLM_PROVIDER` | 默认接口根地址 | 密钥 |
| --- | --- | --- | --- |
| DeepSeek 云端 | `deepseek` | `https://api.deepseek.com` | 必填 |
| 通义千问 / 百炼（北京） | `qwen` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 必填 |
| Ollama 本地 | `ollama` | `http://127.0.0.1:11434` | 默认不需要 |
| LM Studio 本地 | `lmstudio` | `http://127.0.0.1:1234/v1` | 按服务配置 |
| vLLM 自部署 | `vllm` | `http://127.0.0.1:8000/v1` | 按服务配置 |
| 其他 Chat Completions 兼容服务 | `compatible` | 必须手动填写 | 按服务配置 |

模型名称不写死在程序中，请使用服务商控制台中有权限调用的模型 ID，或本地实际安装/加载的模型 ID。不同模型对结构化输出的支持不同；选择支持指令跟随与 JSON 输出的对话模型。预设支持按官方接口实现，真实可用性请用页面连接测试验证。

1. 复制 `.env.example` 为 `.env`（已有 `.env` 时直接编辑，不要覆盖现有密钥）。
2. 从下面选一套配置，填写自己的模型名称；云端还需填写 API Key。不要把密钥写进前端文件、Git 或聊天消息。
3. 停止旧服务，再运行 `npm run dev`。配置仅在启动时读取。
4. 打开“设置与数据”，点击“测试模型连接”。成功表示鉴权、模型调用和 JSON 输出均通过测试；连接测试不保证完整课程生成质量。

连接测试仅发送固定短提示，不发送学习记录；云端测试会产生少量模型调用费用。页面加载和查询状态不会调用模型。

### 国产云端：DeepSeek

```dotenv
LLM_PROVIDER=deepseek
LLM_MODEL=填写控制台中可用的对话模型ID
LLM_API_KEY=填写你的DeepSeek密钥
LLM_BASE_URL=
```

程序自动使用 DeepSeek 根地址、Bearer 鉴权和 JSON Object 输出，并关闭思考模式。模型 ID 请以[官方 API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)为准。

### 国产云端：通义千问 / 百炼

```dotenv
LLM_PROVIDER=qwen
LLM_MODEL=填写百炼控制台中可用的千问模型ID
LLM_API_KEY=填写你的百炼密钥
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

此预设使用北京地域兼容接口，关闭思考模式（`enable_thinking=false`）并开启 JSON Object 输出。若控制台提供的是其他地域或专属工作空间地址，请将 `LLM_BASE_URL` 替换为对应根地址，密钥须与地域/工作空间匹配。参考[百炼接口地址](https://help.aliyun.com/zh/model-studio/model-calling-in-sub-workspace)、[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)和[思考模式](https://help.aliyun.com/zh/model-studio/deep-thinking)。

### 本地：Ollama

安装并启动 [Ollama](https://ollama.com/download)，准备模型后用 `ollama list` 查看准确名称。程序不会自动下载模型。

```dotenv
LLM_PROVIDER=ollama
LLM_MODEL=填写ollama-list显示的完整模型名称
LLM_BASE_URL=http://127.0.0.1:11434
LLM_API_KEY=
```

使用原生 `/api/chat`、`format=json` 与非流式输出，关闭思考。参考 [Ollama 官方接口](https://docs.ollama.com/api/chat)。旧的 `OLLAMA_MODEL`、`OLLAMA_BASE_URL` 仍兼容：仅在 provider 为 ollama 且对应的 `LLM_*` 变量为空时回退到旧变量。

### 本地：LM Studio 或 vLLM

LM Studio：加载模型，在 Developer 中启动服务，模型 ID 使用服务显示的 identifier。

```dotenv
LLM_PROVIDER=lmstudio
LLM_MODEL=填写已加载的模型ID
LLM_BASE_URL=http://127.0.0.1:1234/v1
LLM_API_KEY=
```

vLLM：启动模型服务后，填写实际对外暴露的模型名称（例如部署时设置的 served model name）。

```dotenv
LLM_PROVIDER=vllm
LLM_MODEL=填写服务中的模型名称
LLM_BASE_URL=http://127.0.0.1:8000/v1
LLM_API_KEY=
```

本地服务启用了鉴权时填写对应密钥；部署在局域网另一台设备时，将地址替换为该设备地址。参考 [LM Studio 兼容接口](https://lmstudio.ai/docs/developer/openai-compat/chat-completions)和 [vLLM 客户端地址说明](https://docs.vllm.ai/en/stable/cli/chat/)。兼容服务默认通过提示词要求 JSON，不强加 JSON Object 参数；建议加载非思考对话模型。需要关闭本地思考模式时，在本地服务的模型/模板设置中调整。

### 其他国产服务或自建网关

只要支持 `POST /chat/completions`、`messages`、`max_tokens` 和 `choices[0].message.content`，即可尝试使用兼容模式：

```dotenv
LLM_PROVIDER=compatible
LLM_MODEL=填写服务商提供的模型或推理接入点ID
LLM_BASE_URL=https://你的服务地址/对应版本根路径
LLM_API_KEY=填写该服务的密钥
LLM_JSON_MODE=off
```

`LLM_BASE_URL` 不包含末尾的 `/chat/completions`，程序会自动追加。Ollama 根地址不要附加 `/api/chat`。接口若使用其他协议、专有签名或额外必填参数，尚不能直接使用此适配。兼容性需要以该模型的连接测试和实际生成结果确认。

### 输出参数与排错

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `LLM_JSON_MODE` | `auto` | `auto` 对 Ollama、DeepSeek、千问启用 JSON 模式；其他服务仅使用提示词。`on` 强制启用，`off` 不传格式参数，但仍要求返回 JSON |
| `LLM_MAX_TOKENS` | `8192` | 输出上限，允许 128–32768；不得超过实际模型上限。Ollama 映射到 `num_predict` |
| `LLM_TIMEOUT_MS` | `120000` | 单次调用超时，允许 1000–600000 毫秒，前端等待时间同步调整 |

- “鉴权失败”：检查密钥、账号权限、地域与接口是否匹配。
- “模型或接口不存在”：检查模型 ID、根地址、本地模型是否已安装/加载。
- “限流或额度不足”：检查余额与并发/调用额度，稍后手动重试。
- “不接受当前参数”：检查模型支持的 token 上限与输出格式；不支持 JSON 模式时尝试 `LLM_JSON_MODE=off`，仍不支持则使用合适的对话模型。
- “输出被截断”：提高 `LLM_MAX_TOKENS`，并确保模型支持对应输出长度。
- “超时”：确认服务可用；本地机器推理较慢时可适当增大 `LLM_TIMEOUT_MS`。
- “未返回有效 JSON”：模型可能输出了思考过程、额外解释或空正文；切换到非思考模式或更适合结构化输出的模型。

不会自动回退到其他服务，也不会自动重复计费请求。失败时手动重试。API Key 不会通过状态接口返回，上游错误正文也不会直接回显。

配置后可以：

- 输入目标、现有基础、每天学习时间、周期，生成 3–12 节课程的个性化路线。
- 进入课程并点击生成，获得讲解、示例、实践任务、单选测验与关键收获。
- 阅读课程时，可在已生成的内容块或旧课程讲解段落主动生成知识卡片，不必先通过练习；AI 根据选定内容生成草稿，示例模式提供课程摘录草稿。检查并编辑标题、知识描述、Markdown 正文、适用／不适用场景及标签后，确认才保存。同一课可以保存多张卡片；本课已有相近卡片时会提示核对。
- 阅读页可收起或展开左侧课程目录。已生成的知识讲解和配套案例各有独立的“收起／展开”按钮，收起时保留标题与学习目标，正文及配图暂时隐藏；状态在当前窗口切换页面时保留。分步课程不再重复显示顶部“更多学习工具”；讲解块的“换个讲法”和案例块的“换个例子”直接常驻，制作知识卡片、配图、恢复版本等仍在各内容块的“更多学习工具”下拉菜单里，菜单悬浮显示，不会撑高课程卡片。AI 朗读统一在右侧“AI 答疑”下方。旧版固定结构课程保留整课工具入口。选中课程原文后点击浮出的“添加笔记”，可写随文批注；正文只出现可点击的小标记，不改动课程内容。批注可查看、修改或删除，桌面版随课程保存在本机并进入完整备份。之后制作本课或该段知识卡片时，最近的相关批注会以“我的笔记”附在草稿末尾供检查，个人想法不会自动当作已核验事实；已经保存的旧卡片不会被自动改写。
- 向知识库提问；模型仅依据提供的卡片回答，并列出卡片引用。服务端检查引用 ID 是否存在，但不能保证模型每句话都忠实于来源，请核对重要内容。

模型生成默认等待两分钟，可通过配置调整；失败时保留现有内容并显示可重试的错误。服务器验证模型结果的结构和学习时间预算，不合格的结果不会加入路线。

## 学习闭环

1. 从概览开始第一课，或新建 AI 路线。
2. 阅读讲解与示例，在自己的工具中完成实践任务。页面不会执行用户代码，也不会验证外部动手任务的完成情况。
3. 提交随堂测验，查看得分和解析。全部答对后记录为已掌握，可以反复练习；后续复习出错不会撤销过去的完成记录，练习页面会优先显示最近答错的课程。
4. 阅读时可添加随文笔记；在“更多学习工具”里制作本课或某段知识卡片，练习完成后也能直接制作本课卡片。草稿确认后才会保存，可为同一课制作多张。
5. 搜索、编辑、关联、导出或删除知识卡片。在示例模式下，知识对话返回关键词检索结果；配置模型后启用 AI 问答。

## 数据与当前边界

- 桌面版数据保存在本机文件；Web 版使用当前浏览器 localStorage。无登录、云同步或多用户服务。
- 设置页可导出完整 JSON 备份，Wiki 可导出 Markdown。桌面版支持备份导入，Web 版尚不支持。清理浏览器网站数据只影响 Web 版记录。
- AI 请求会把相关目标、课程或笔记发给 `.env` 指定的模型服务。云端配置会把这些内容发送到服务商；本地配置发送到对应部署服务。密钥仅保存在服务端配置，前端不持有模型密钥。
- Wiki 问答先从全库按主题、标题、标签、摘要和正文做本地相关度检索，每次最多向模型发送 12 张相关卡片，并可补入这些卡片已有的显式关系；尚未引入向量数据库或全库语义检索，未建立的关系不会自动补全。
- 首版未包含代码沙箱、自由作答自动评分、间隔复习算法、联网课程检索或学习进度自动重规划。
- 模型配置和资料存储适合个人本地原型。面向公网部署需要另行设计身份验证、数据库、用量控制与部署策略。
