# 随堂练习追加与逐题掌握

## 使用方式

分块课程的“随堂练习”页，在现有题目下方选择“新增题数”，点击“继续生成题目”。每次 1–5 题，默认 4 题，可多次追加；每课最多保留 100 题，与现有成绩和课程上下文上限一致。只增加独立的补充练习块，原题、正文和成绩历史不替换。旧固定结构示例课程支持已答对题目免重做，但不提供追加入口，不自动转换结构。

仅点击追加才调用当前课程生成模型，可能计费。仍只按已讲内容出题、复用本课有效引用，不重新联网搜索；质量审查已开启时沿用独立审查流程。不会批量自动生成后续组，也不在失败后自动重试。

## 通过记录

- 本次或已有版本中确实答对的原题直接显示“已通过”、正确选项和解析，不再显示答题控件。
- 只提交尚未通过的题与新题；程序补入已通过题的正确选项再计算当前整套成绩，不能将缺失答案默认为 A。
- 只有题干、四个选项、正确答案和解析完全一致才复用通过记录；调换题目顺序不影响，修改内容则需要重新作答，不按位置迁移成绩。
- 全部当前题目通过后不再要求提交，可继续追加或制作知识卡片。追加新题后，当前整套练习需完成新题才算全部通过；旧版本成绩单独保留，不拿旧答卷给新题评分。

桌面版使用原有 `quizRecords` 的题目版本、答卷和最多 50 份历史快照，不新增存储表，也不更改备份格式。首次向未建版本记录的旧练习追加时，会先记录原题与原成绩。Web 版使用相同 SHA-256 版本规则保存在浏览器中。完整学习备份包含题目和个人成绩；分享课程包仍不携带个人成绩或通过记录。

## 失败与保护

每次请求明确给出新增题数与已有题干，要求模型更换题目角度、不要重复。服务端在调用前校验题数和总量，保存前校验实际数量、结构、同组重复及与当前已有题干的规范化精确重复。不会仅凭字面检测声称排除了所有语义重复。未知资料引用仍会被拒绝，不删除引用强行保存。

同课禁止并发追加。失败保留原题和成绩，并保留一个未生成的补充练习块以供手动重试，不因重试不断添加空题组。若新题已经保存、只有随后质量审查失败，则重新读取本地题目，不覆盖已保存题目，也不重复生成该组。读取题目时同时读取对应成绩，恢复旧版本后不把另一版本的答卷误当成当前通过记录。

## 验证

```powershell
node --test --test-isolation=none
node desktop/start.cjs --smoke-test --quiz-only
```

自动测试使用本地模拟模型，不消耗真实 Key。桌面回归覆盖原有 4 题追加到 8 题、仅填写未通过题目的答案、原题不被替换、通过后显示答案、重新打开、失败保留成绩，以及复用待重试题组。
