# 课程分享（桌面版）

在“我的课程”页面选择一条路线，点击“导出课程包”。将生成的 `课程名.learnflow-course.json` 发给其他用户；接收方在同页点击“导入课程包”，确认标题和内容数量后新增课程。

## 分享范围

分享单位是一条完整课程路线（包含其所有章节）。包含目录、课程目标与说明、当前已生成的正文、测验题与答案解析、当前配图及来源署名、正文引用和参考文档。未生成章节或模块保留为空，导出与导入时明确提示，不调用模型补齐。

不包含个人知识卡片、原文批注、心得、聊天、成绩、学习进度、需求澄清问答、生成配图的原提示词、旧正文版本、评审报告、模型配置和 Key。原文、标题、目标或配图本身若包含个人信息，仍需分享者检查；字段隔离不等于自动脱敏。也请确认有权传播相关内容与图片。

接收方不需要 Key 即可阅读已生成内容；继续生成、问答等功能使用接收方自己的模型配置。导入不自动联网、不执行课程代码，不将分享课程视作已经过事实核验。

## 导入与安全

- 课程包为独立版本格式 `learnflow-course`，版本 `1`，文件上限 250 MB；不是完整学习备份，不要使用“恢复学习备份”导入它。
- 接收方始终新增副本，同名也不覆盖。课程、章节、内容块重新分配 ID，进度从零开始，原学习数据不变。
- 使用字段白名单重新构建教学数据；验证课程、正文、练习结构。当前配图内嵌 Base64，校验文件类型、大小及 SHA-256；缺图或损坏时拒绝导入，不从网络补图。
- 确认前不修改学习库。新增课程在单个 SQLite 事务中完成；图片先以不可变资源写入，若后续数据库写入失败，可能留下未引用图片，但不会覆盖原课程。
- 第一版面向桌面测试版及后续安装包。浏览器版暂不显示课程包入口；旧安装包需更新到包含本功能的版本。

## 验证

离线测试覆盖导出字段隔离、正文与引用保留、部分生成课程、历史格式、重复导入的 ID 隔离、现有数据不变、无效格式、配图携带与损坏检测，以及前端导出/导入/取消/失败交互。不使用真实模型 Key。
