# 课程分类

在“学习路线 → 我的课程分类”按领域浏览课程。右上角“调整分类”支持一次修改多条课程，点击“保存分类”后立即重新分组。每条课程归入一个分类；只展示有课程的分组。

## 搜索与按需展开

- 默认只展开当前课程所在分类，其余分类显示名称与课程数量。点击整行标题可展开或收起，也可用“全部展开／全部收起”统一操作。
- 搜索覆盖课程名称、分类、学习目标、章节标题和标签；忽略英文大小写及全角半角差异。多个关键词用空格分隔，全部匹配才显示。
- 搜索时只保留匹配课程并自动展开对应分类，显示匹配课程及分类数量；无结果时可清空或修改关键词。
- 搜索期间也可收起结果。清空搜索后恢复搜索前的展开状态；输入搜索时不替换搜索框，保留焦点与输入状态。
- 搜索与展开选择仅保留在本次运行会话中，切换页面后仍可继续使用，不写入课程、备份或分享包，也不调用模型。

## 自动判断规则

规则在本机执行，不调用大模型或搜索服务。依次检查：课程标题 → 学习目标 → 课程说明 → 章节标题 → 章节目标 → 章节标签。在某一项识别出分类后停止，避免正文或标签偶尔提到工具就改变整门课程的主题。匹配忽略英文大小写，并统一全角、半角字符。

同一项命中多个分类时，按下表顺序选择。具体工具和学科关键词优先于“管理、投资”等泛化词；规则仍可能误判，可用手动分类纠正。

| 分类 | 常见识别词与示例 |
| --- | --- |
| AI 与大模型 | LLM、GPT、RAG、提示词、智能体、人工智能 |
| 办公与自动化 | Word、PowerPoint、Office、WPS、UiPath、RPA、VBA、办公自动化 |
| 数据分析 | Excel、Power BI、DAX、Power Query、SQL、数据库、统计、报表 |
| 开发工具 | Git、GitHub、Docker、Linux、Kubernetes、版本控制、运维 |
| 编程开发 | Python、JavaScript、Java、Rust、编程、前后端、自动化脚本 |
| 语言与沟通 | 英语／英文、日语、口语、听力、演讲、写作、沟通 |
| 游戏与兴趣 | 游戏、电竞、三角洲行动等 |
| 财税与法务 | 财税、发票、会计、税法、合同／合约、合规、审计、IFRS |
| 商业与管理 | 公司间定价、转移价格、MTP、ICO、营销、项目管理、供应链 |
| 设计与创作 | 摄影、绘画、剪辑、音乐、Figma、Blender、创作 |
| 科学与通识 | 数学、物理、心理学、历史、哲学、经济学 |
| 生活与兴趣 | 健身、烹饪、旅行、园艺、理财 |
| 其他主题 | 未命中规则时的兜底；也可手动选择 |

例如，“UiPath RPA 办公自动化与财务对账”归入办公与自动化，“英文跨部门会议”归入语言与沟通，“公司间转移价格 ICO 与 MTP”归入商业与管理。自动分类按当前规则计算，后续规则更新可能改变尚未手动设置的课程分组。

## 手动选择与保存

- 下拉框默认“自动分类（当前建议）”。选择具体分类后，手动选择优先于自动规则，重启后仍保留。
- 重新选择“自动分类”并保存，会删除手动覆盖，恢复按当前规则判断。
- 分类保存只改变路线的分类元数据，不修改课程正文、章节、成绩或学习位置；批量保存要么全部成功，要么全部保留原值。失败时保留弹窗中的选择，可修正后重试。
- 桌面版保存在 SQLite 元数据 `plan_category:<路线ID>`；浏览器版保存在当前浏览器的 localStorage。两种模式的数据互相独立。
- 完整学习备份、恢复及课程包导入导出保留手动分类。删除课程时同步清理该字段。

当前支持在固定分类之间调整，不提供自定义类别名称。

## 与知识库的关系

课程分类与知识库领域使用同一套判断规则，手动选择也同步生效。知识库保留原有九个顶层领域及图谱颜色：办公与自动化、开发工具、编程开发映射到“技术与开发”；财税与法务、商业与管理映射到“商业与管理”；游戏与兴趣、生活与兴趣映射到“生活与兴趣”；其他主题映射到“待归类”。其余分类对应同名或近义领域。

这里调整的是卡片所属课程的领域，不覆盖卡片内部的主题分类，也不移动 Markdown 文件。

## 验证

`test/course-categories.test.mjs` 覆盖规则样例、手动优先、自动恢复、事务失败、重启、完整备份及课程包。`test/client.test.mjs` 覆盖桌面和浏览器保存失败时的数据与草稿保留，以及默认折叠、组合关键词搜索、清空恢复、输入焦点和课程切换。

```powershell
node --test --test-isolation=none
node desktop/start.cjs --smoke-test --categories-only
```

桌面专项在隔离目录使用示例课程，验证搜索、折叠、输入焦点、实际分组、手动保存、重载保留、恢复自动分类，以及窄屏搜索区与弹窗，不调用真实模型。
