# 学习位置与继续学习

## 使用方式

每条学习路线分别保存最近一次停留位置。首页“继续你的学习”显示上次章节与栏目，点击“继续学习”后加载对应章节，再恢复栏目和栏目内偏移；不再总是打开第一节未通过测验的课。“推荐下一步”仍按测验进度计算，与阅读位置独立。

支持分块课程的讲解、案例、实践、总结和练习栏，也支持旧式课程的讲解段落、示例与实践。练习页记录题目位置，答疑页记录对话位置；不会自动提交答案、修改成绩或调用模型。课程目录与本课内容块的折叠状态随位置保存。

旧版没有保存阅读位置，无法精确还原更新前曾停留的栏目；从更新后第一次进入章节开始记录。没有位置记录时，沿用原来的推荐课程作为起点。

## 保存与恢复保护

- 滚动停止后短暂防抖保存，切换章节、离开学习页时主动保存；关闭或刷新桌面窗口前以受保护的同步 IPC 完成一次有界的本地元数据写入，不涉及网络。
- 用章节 ID 和栏目 ID 定位，不用“第几个栏目”替代稳定身份。旧式段落、题目和对话另存布局内容指纹，顺序变化时可查找仍然相同的内容。
- 内容已改写时不沿用旧偏移；栏目被删除时回到该课标题，章节或路线失效时回到有效的推荐课程。不会据此重写原课程。
- 恢复按新布局计算并限制偏移；用户开始滚动或操作后，取消待执行的自动定位，避免迟到的图片加载或恢复回调抢走当前位置。
- 保存失败提示用户，当前窗口仍可保留位置；不因此改变测验完成状态或覆盖课程正文。

## 存储与隐私

`studyPositions` 为可选的按路线索引字段，包含章节、页签、栏目身份、布局指纹、偏移、显示名称、折叠状态和时间。不保存课程全文、未提交答卷、密钥或其他模型参数。

桌面版写入现有 SQLite `meta`，不新增数据库版本；Web 版随本地学习状态保存。完整 JSON 备份和恢复包含位置，旧备份可继续使用。分享课程包不携带个人学习位置。删除路线时同步清理当前位置及已有 JSON 备份中的相应位置。

## 验证

`node --test --test-isolation=none` 覆盖布局锚点、偏移、失效回退、手动操作取消恢复、跨路线校验、数据库重开、完整备份和分享排除。

`node desktop/start.cjs --smoke-test --resume-only` 使用隔离数据库和合成课程，验证第二课实践栏目、关闭前同步保存、刷新后继续、题目位置、旧式章节以及不同路线互不覆盖。测试不调用真实模型，末尾生成 `resume-on-quit.expected.json`，供进程退出后核对实际 SQLite 记录。
