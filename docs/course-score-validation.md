# 课程评分校验与未核实意见

更新日期：2026-10-20。

## 处理边界

课程评分仍是只读操作，不修改课程、练习、成绩或笔记。评分模型与生成模型互斥；只有主动评分才调用模型，失败不自动重试。

一次真实诊断发现：模型完整返回7个评分维度和6道题的独立解答，但7条辅助意见中有2条引文无法在对应正文逐字定位，导致旧逻辑拒绝整份评分。本次将评分结构校验与辅助引文定位分开，而不是放宽分值、猜测答案或忽略模型问题。

## 新规则

- 评分维度必须完整、无重复，单项为0–4整数且有非空理由；评分说明、辅助意见字段及逐题独立解答仍完整校验。解答不能缺题、重复或使用无效模块/题号。失败提示具体字段，不以默认值补齐，不自动调用模型修复。
- 辅助引文优先逐字匹配；仅加粗、行内代码边界和非代码空白等展示差异，可使用已有严格匹配器映射回真实原文。不会模糊匹配改写、数字、否定、标点或代码差异。
- 测验引文只能定位到一个题干或一个选项，不能把多个字段或题目拼成“原文”，也不能引用未发送给独立解题模型的标准答案与解析。
- 字段合法、但引文无法定位的辅助意见保留在程序构造的`unverifiedIssues`中，不进入正常`issues`，不作为已确认错误、修订目标，也不通过其严重级别直接改变报告状态。模型不能自行将意见标记为已核实。
- 维度评分、理由和说明保留模型原评估，不因引文未定位而自动加分、减分或改写。模型的维度判断仍可能受到自身疑点影响，因此页面明确提示“未核实”“评分不等于事实核验”，不能把引文定位成功理解为观点已被证实。
- 无需逐字引文的`kind=missing`仍按既有规则允许空引文，但必须对应已生成模块，且有完整理由与建议。这是模型的缺失判断，不是外部核验结论。

## 展示与兼容

保留总分、各维度、评分说明和历史。若有未核实意见，显示数量及边界提示，详情默认折叠；引文明确标注为模型提供且未定位，不冒充课程原文。所有模型文本按纯文本转义，不恢复问题勾选、定位或手动修订工作台。

报告增加可选的`unverifiedIssues`数组，最多60项，随现有JSON报告存入SQLite，无需修改数据库表或报告版本。旧报告无该字段时正常读取；新字段随完整备份、恢复和历史记录保存。旧报告与课程原文不会被重写。

严格的`validQualityJudgment`与旧修订检查不放宽；只有只读评分流程使用独立的规范化步骤。自动事实核查和修正流程不变。取消评分仍会丢弃本轮全部结果，迟到返回不得保存。
