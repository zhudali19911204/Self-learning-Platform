# 浏览后调整课程目录

新建课程在正式创建前已支持循环澄清和大纲预览，见 [调研与预览循环](planning-preview-loop.md)。本文描述已创建课程的后续目录调整。

入口位于学习工作台的课程目录顶部，以及学习路线页的课程操作栏。适用于需求调研并生成路线后，用户浏览章节再提出补充要求。

## 使用流程

1. 点击“调整课程目录”，填写增删章节、调整顺序、拆分案例或改变讲解难度等要求，最多 1000 字。
2. 点击“生成调整预览（可能计费）”。沿用原学习目标、基础、每天投入、周期及已确认的调研回答，不重新生成问卷。
3. 对照原目录和新目录，查看章节目标、时长及调整说明。改变要求后需重新生成预览；失败时保留要求和已有预览。
4. 点击“确认保存调整版”，新增独立课程并切换过去。保存不调用模型；未确认、取消或关闭预览都不保存新课程。

当前按既有课程结构支持 3–12 节，总时长不超过原计划预算。模型可能无法满足全部要求，需要用户查看调整说明和新目录；不承诺自动识别所有语义遗漏。

## 已有内容与资料

- 原课程的目录、正文、练习、成绩、聊天、笔记和阅读位置保留。调整版使用新的课程与章节 ID，进度从零开始，正文按需重新生成，避免旧正文对应到错误的新章节。
- 原课程的手动分类沿用到调整版；自动分类仍按新标题和课程信息判断。
- 导入资料课程直接读取已保存的文字快照，不要求重新导入。服务器检索时纳入本次调整要求，仍遵循全库目录及单次片段预算；不自动联网或补写资料未覆盖的知识。
- 本功能只调整规划，不调用评分、事实核查、配图或语音服务，也不复制旧章节的联网开关。

## 需求上下文与保存

新路线保留原 `learningBrief`，将本轮要求加入 `learningBrief.adjustments`，最多保留最近 10 次。最新要求优先于冲突的旧偏好，后续大纲和正文继续接收这份需求上下文。没有调研记录的旧课程或分享课程也可调整，保留空回答数组，不伪造问卷回答。

桌面版从 SQLite 中读取原路线及绑定资料，不采信客户端伪造的原目录、学习约束或资料 ID。发送给模型的原目录快照仅包含规划字段、章节元数据和确认需求，不包含正文、成绩、个人卡片或聊天。

调整版及需求上下文随完整学习备份保存。课程包继续沿用分享字段白名单：包含调整后的目录与当前生成内容，不导出原需求问卷或调整要求。模型配置和 Key 不包含在学习备份或课程包中。

## 调用与失败处理

预览调用当前课程生成模型，可能计费；复用路线生成的结构、重复目标和预算校验。首次结构不合格时最多追加一次格式修正请求，网络错误不自动重试。每次手动重新生成可能再次计费。

生成进入右下角任务列表，可取消；确认保存前结果仅在内存。生成结束后若没有其他运行任务，会收起进度卡片以便查看预览。保存失败保留预览，可再次确认，无需重新生成。

## 验证

```powershell
node --test --test-isolation=none
node desktop/start.cjs --smoke-test --plan-adjust-only
```

测试覆盖调研上下文延续、无问卷旧课程、输入校验、原目录字段隔离、资料复用、预览不落库、过期预览拒绝、取消、生成与保存失败、原正文和聊天保留、SQLite 重启、完整备份及宽窄屏展示。桌面专项使用独立目录与模拟模型，不消耗真实 Key。
