# 调研、大纲预览与确认创建

新建课程采用四步流程：**描述需求 → 澄清方向 → 大纲预览 → 确认生成**。第三步可以反复返回第二步，预览期间仅保留草稿，直到最终确认才新增一门课程。

## 用户操作

1. 描述目标、基础、每天投入和周期，可导入自己的资料。
2. 回答澄清问题并补充学习要求，点击“生成课程大纲预览”。预览展示课程名称、范围说明、每节标题、目标、阶段、标签和时长。
3. 不满意时展开“不满意？补充调整要求”，描述希望增删、重排或改变难度的内容，再生成一版；也可点击“继续澄清方向”，修改上轮答案。
4. 返回澄清后，可选择“重新梳理问题”或“深入澄清”。这时会把上版大纲、已确认回答和最新反馈提供给模型，围绕剩余取舍继续访谈；成功后替换问卷，需重新回答，失败则保留原问卷和回答。
5. 满意后点击“大纲满意，下一步”，在最终确认页核对大纲与需求，再点击“确认并生成课程”。

最后一步直接保存已认可的大纲，不再次生成目录。详细正文、案例、实践和练习仍在课程页按模块生成，不自动批量生成所有章节。

## 草稿与失败处理

- 每次预览和调整都不写入课程列表，不产生额外课程副本。关闭窗口后在本次运行中可继续草稿；未确认的草稿不会进入学习备份，重启程序后不保留。
- 修改反馈后，满意按钮暂停使用，需先生成对应的新大纲。改变问卷答案、目标、时间或资料后，旧预览也不能直接确认。
- 返回澄清但未改变任何条件时，继续使用现有预览，不重复付费生成。
- 生成失败或取消不会创建课程；已有回答、反馈和上版预览保留。保存失败保留最终确认页和认可的大纲，重试保存不调用模型。
- 生成和保存期间禁止重复提交或关闭向导。最终保存仍由 SQLite 或浏览器存储校验，成功后只新增一门课程。

## 需求上下文与资料

当前问卷答案和学习补充构成最新 `learningBrief`。调整预览时保留最近 10 次 `learningBrief.adjustments`，新回答和本轮要求优先于冲突的旧偏好。当前大纲使用新的 ID 作为草稿，最终保存使用同一份 ID 和目录，不把旧正文或成绩套入新目录。

`/api/plan` 的可选 `previewRevision` 包含上版规划快照和本轮要求，可调整尚未保存的大纲；不会查找不存在的已保存课程。`/api/plan-clarify` 的可选 `previewContext` 提供上版目录、确认回答和反馈，供进一步访谈；规划快照不包含正文、聊天、成绩或笔记。

导入资料继续使用本次已解析的资料库，预览期间不提前清理资料。大纲预览和每次调整均使用完整原文或逐批全文整理后的知识清单，并校验资料到课程的逐项安排；预览可展开覆盖清单。相同模型和资料可复用本次运行内的完整整理缓存，不自动联网。最终保存课程时一并保存资料与覆盖清单，详见[完整资料大纲规划](material-outline-coverage.md)。

## 调用与验证

问卷分析、问卷生成、大纲预览及每次手动调整都可能调用模型并计费，沿用既有的有界格式修正规则。系统不会自行循环调用直到满意，每一轮由用户主动发起；进入最终确认和保存不会调用模型。

```powershell
node --test --test-isolation=none
node desktop/start.cjs --smoke-test --planning-only
node desktop/start.cjs --smoke-test --materials-only
```

验证覆盖三版预览、返回澄清、按反馈生成新问卷、待应用反馈拦截、生成与保存失败、存储空间不足、重复提交、关闭草稿、最终目录一致性、导入 20 份资料、宽窄屏和重启后正式课程保留。使用独立模拟模型与隔离数据，不消耗真实 Key。
