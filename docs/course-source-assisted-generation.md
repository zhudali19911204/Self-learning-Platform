# 课程正文联网资料辅助生成

更新日期：2026-10-19。

## 使用方式

课程页标题下提供一个独立的“联网搜索”开关，按课程保存，首次默认关闭。与网页搜图开关互不影响；打开开关本身不请求搜索或模型。

- 关闭：正文、案例、实践、测验和总结继续由当前文字模型生成。
- 开启：生成讲解、案例、实践和总结，或点击“换个讲法／换个例子／换个任务”时，先搜索并排除不适合的来源，再读取网页正文片段，最后交给当前模型生成。随堂练习除外：只根据已讲正文出题，复用已有资料，不重新搜索。优先检索官方文档与原始资料，生成过程中锁定开关与重复生成操作。
- 大纲、学习路线、答疑不因此自动联网。旧固定结构示例课程保持原样。
- 课末“参考文档”按网址去重，显示文档标题、发布机构、读取日期、使用该资料的模块；可展开查看课程表述对应的原文。仅列当前正文所用资料，不列未使用的搜索结果和已替换版本的引用。
- 开关关闭不移除旧正文的参考文档；重新生成和恢复上一版时引用随对应版本变化。参考文档默认折叠，显示文档篇数，点击标题栏可展开或收起。完整 JSON 备份包含开关及引用；删除课程时同步清理。
- 正文中的 `[S1E1]` 等引用标记可直接打开对应资料原文，悬停显示文档标题；仅链接当前模块已保存且未被排除的引用。代码中的标记、无法匹配的标记保持原样，不猜测来源。显示时不修改正文或笔记定位文字。

### 随堂练习复用已讲内容

无论“联网搜索”开关开启或关闭，随堂练习均不发起新的搜索 API 或网页读取。桌面版从实际保存的本课前序讲解、案例和教学任务重建教学上下文，只复用本次确实提供给模型的正文片段所关联的有效资料。未生成、未来、被省略或已编辑失配的句段不能提供资料，命中当前排除规则的来源也不会复用；最多3个网页、每页8段，按网址与实际引文去重。

各模块原有片段编号可能重名，本次出题重新统一分配 `S1E1` 等编号。发送给模型的前文中，普通文本里的旧引用标记暂时隐藏，并保持字符位置不变；代码、转义文本、HTML和链接不修改，课程原文也不改写。模型只能使用本次实际提供的编号，实际引用的编号、来源与对应解析仍严格校验；不存在的编号不会被忽略或自动替换成其他资料。

不再强制每道解析必须附外部引用。理解、情境应用、归纳等仅依据已讲内容的解析可以不附引用，即使本次提供了可复用网页资料也一样；只有真正使用资料的句段才标注引用。允许一组题中部分解析有引用、部分没有，或全部仅依据已讲内容。不为缺少引用的题补造标记，不把未使用的网页登记为练习的参考依据。显式报告资料不足、未知或被排除的片段ID、对应不到解析的引用，以及题目结构或答案格式错误仍会阻止保存；讲解等非测验模块的引用要求保持不变。这是避免引用配额导致整组题误失败，不代表无引用解析已通过事实核验，仍可使用独立质量审查。

没有可复用资料时，仅依据已讲正文生成理解与应用题，不要求附上外部引用，也不主动搜索或声称事实已联网核实。非桌面无服务端课程存储的模式同样只依据传入的教学正文，不接受客户端随意附带的网页作为已读取资料。练习只覆盖已提供知识，不因为资料含有其他细节而扩大考试范围；资料快照沿用原读取时间，不伪装成最新读取。界面明确显示复用资料／仅依据已讲内容，失败不自动重试。

### 动手实践等模块的引用编号隔离

资料编号仅在本次生成的 `officialDocuments` 中有效，不能沿用其他模块或旧稿的同名编号。讲解、案例、实践、总结生成以及“换个讲法／换个例子／换个任务”现在也在请求副本中隐藏导语、前序正文、配套案例、教学片段和 `currentExcerpt` 中普通文本的旧引用，并在提示中列出本次真正可用的片段编号。代码、HTML、转义文本及链接内容保留为字面内容，不作为新资料依据；列表、引用块中的代码同样保留。正文、旧稿历史和引用备份不因此改写，教学片段的位置与长度不变。

这修复了前文旧编号与新搜索结果混入同一次生成请求的输入问题，不会猜测旧编号该对应哪个新网页，也不会删除生成结果中的未知标记来强行保存。实践自拟场景、数据明确标为教学示例，不为每条任务指令硬凑引用；涉及实际知识的结论仍使用本次实际资料。不存在的编号、已排除的来源和缺少必要引用仍会阻止保存。联网开关、搜索次数上限和随堂练习不重新搜索的规则不变，不增加自动重试。

## 支持的搜索服务

目前沿用已保存的百炼文字模型、地址和密钥，调用同源 `/compatible-mode/v1/responses` 的 `web_search` 工具。需使用支持该工具的模型与服务权限。当前为纯本机模型或其他不支持的服务时会明确报错，可关闭开关继续普通生成；不会更换模型、服务地址或账号。

协议依据：[阿里云百炼联网搜索文档](https://help.aliyun.com/zh/model-studio/web-search)。只接收实际完成的 `web_search_call.action.sources` 链接，不从模型回复正文中提取网址。

每次需要新检索的正文生成最多发送一次搜索 API 请求，再读取最多三篇通过排除规则的网页，随后发送一次课程生成请求；随堂练习不搜索。单个搜索响应内供应商的工具可能执行多次检索，因此一次 API 请求不等于一次工具计费。搜索与生成可能计费；不自动重试、不在失败后退回模型记忆生成。只把课程与模块标题、目标传给搜索，不传个人笔记、聊天或模型密钥；网页读取不附带密钥与 Cookie。

## 来源与引文规则

按用户要求，来源准入已从允许名单改为排除名单。规则集中在 `public/course-sources.js` 的 `excludedSourceDomains`：默认排除知乎、CSDN、博客园、简书、掘金、百度百家号/贴吧/知道/百科、头条、搜狐、微博、小红书、抖音、B站、微信公众号、Reddit、Quora、Medium、Dev.to、Blogspot、WordPress.com、Stack Overflow/Stack Exchange、Wikipedia、Fandom 等问答、自媒体、博客、百科及聚合来源，覆盖列出域名及其子域名。这是课程资料选取策略，不意味着这些平台所有内容都错误。

此外排除明显的 community/forum/blog 子域名和论坛、问答、评论等页面路径；未被排除的新公共 HTTPS 网站可以直接使用，无需逐个登记。保留文章 ID、语言等正常查询参数，去除跟踪参数，拒绝包含跳转目标的查询参数。`officialSourceRules` 仅用于已知机构的名称显示，`officialSource`、`officialDocuments` 等旧命名为接口兼容保留，不再表示允许名单或权威性认证。国家税务总局及政策法规库可以直接参与检索；税务等内容要求模型检查生效、废止、地区及主体，未被排除并不保证网页可靠或政策有效。

搜索结果在读取前过滤；重定向每一跳重新检查域名、路径和 DNS。禁止内网、回环及保留 IP，连接固定到已检查的 DNS 地址，保留 HTTPS 证书验证。读取仅支持公开 HTML 或纯文本，每页最多 2 MB、三次重定向，每跳读取最多 20 秒；不会登录、运行页面脚本或绕过访问限制。PDF、纯 JavaScript 页面可能读取失败。

HTML 提取排除脚本、导航、表单、隐藏内容和显式评论区。每页从正文按主题关键词选取最多六段，每段约 1100 字符，保留片段原文，所有资料最多约 19800 字符。提示词要求模型自行检查资料相关性、版本和适用范围；不足时返回明确的“资料不足”。关键词选取不等于语义相关性核验。

模型直接在正文句段末尾写 `[S1E1]`，连续多个来源写作 `[S1E1][S2E1]`。程序从标记之前的当前段落提取实际原文（至多末尾600字符），自动填写网址、标题、机构/域名、读取时间和来源片段。模型不再需要重复复制 claim；即使另外返回了改写后的 claim，也以正文标记位置为准。引用按结论需要标注，同一资料允许支持多个句段，不再使用12处上限；生成与保存统一设置256条的异常数据保护上限，完全相同的片段ID与句段只保存一次，不截断或丢弃其他有效引用。代码、HTML和链接中的标记不作为引用依据；孤立标记和不存在的片段ID被拒绝。测验只在解析实际使用网页片段时附引用，不设置每题最低数量要求。该机制不能证明原文一定支撑结论，也不能保证课程完全没有错误，现有独立质量评审仍有价值。

兼容没有正文标记的旧版 claim 响应：先按原文精确匹配，再容忍 Markdown 加粗、强调、行内代码标记及普通文本空白差异。不会忽略数字、否定词、运算符或代码内部空格，也不做模糊语义匹配。新格式直接从正文提取句段，减少复制/改写导致的不对应报错，仍校验资料片段来自实际检索和读取。

旧版 `quotes_checked` 引用和 `sourceBundles` 快照保持读取与备份兼容，不作为新检索的自动来源。历史引用若命中当前排除规则，保留原有记录但不提供打开链接的入口。

批量质量修订暂未接入搜索：开关开启时，批量生成在调用模型前提示改用模块级修订。关闭后可用原批量修订流程，新稿不继承旧稿引用；撤销整个修订会恢复原稿引用。

### 联网失败原因的传递（2026-10-16）

已复现旧链路将搜索 HTTP 503 等预期错误统一变成 HTTP 500 和“服务发生错误，请稍后重试”：资料模块抛出的普通 Error 缺少状态，被服务端兜底隐藏。此复现使用模拟搜索，不代表截图中那一次失败已经确认为 503；该次原始异常未留存。

资料模块现在通过 `CourseSourceError` 返回可展示的安全消息、HTTP 状态、阶段和错误代码，区分模型配置、搜索鉴权、余额/限流、参数支持、上游不可用、连接或响应读取超时、结果解析及无有效来源。API 返回 `error`，并对这类已知错误附加 `code`、`stage`；未知程序异常仍不直接公开内部消息。

最多三页全部读取失败时，汇总已尝试页数和原因类别，包括域名解析、网络/证书、超时、格式限制及正文不足；不回传上游错误原文、私有网址或密钥。有一页可用即可继续。读取响应中的空对象和空条目也会被安全处理。既有费用边界不变，不自动重试搜索或生成，不在无资料时退回模型记忆生成。

本轮测试使用模拟 HTTP、流式响应和网页结果，覆盖 400/401/402/403/429/503/504、连接与读取超时、无效结果、全部网页不可读及部分网页可读。未调用真实 Key；修复错误传递并不能消除服务商或资料网站自身的可用性问题。
