# 用完整资料规划课程大纲

2026-11-05。适用于新建资料课程的大纲预览、预览反馈调整，以及已保存课程的“调整课程目录”。旧课程不会自动重写。

## 读取与覆盖

- 以已导入的全部提取文字为范围，不再根据中文目标只抽取英文文档中的少量片段。短资料的完整规划输入不超过28000字符时，一次提供每个原片段的全文、文件、位置及内容标题。
- 长资料仍按文件和原文顺序完整分批，每批约16000字符、最多100个原片段。模型按关联主题合并片段，返回1–40项紧凑索引：主题/知识名称、核心用途及必要先修或边界标签、实际片段ID列表。不再要求每段独立写详细摘要，也不提前抄写完整公式、参数、数值、步骤和案例；具体教学仍回到原文。
- 每个片段ID必须在本批主题索引中至少被一个主题覆盖。同一片段包含多个知识点时，不同主题可以共同引用；同一主题内重复编号、未知/跨批次编号、漏段或空索引仍拒绝作为有效结果。覆盖统计按原始文件和片段去重，不因多个主题引用而重复计数，也不会用重复引用代替遗漏的片段。编号错误会区分具体批次及错误类型。每个主题标题最多80字符、范围说明最多240字符，全部主题文字合计最多3000字符（原详细摘要上限10000字符）；索引请求输出上限为4096 token，模型原设置更低时取较低值，最终大纲及其他任务不降低输出上限。字符上限和token上限不是实际输出量或速度承诺。
- 根据全文或全部批次清单规划课程，要求模型为每个 `U` 单元返回对应课程位置。关联内容可合并到一课，不能为满足时长而静默删减后续资料。页眉、目录、版权等辅助内容需要明确理由；程序识别到章节、公式、必须/禁止等规则的单元不允许仅归为辅助资料。
- 漏项、重复或无效课程位置会触发最多一次大纲格式修正；仍不合格则没有可确认的大纲。模型明确报告课时不足时，提示增加时间或拆分路线，不保存部分大纲、不自动补造规则。
- 标题提取会避开反复出现的相同页眉，原文仍完整保留。已有问卷或旧大纲里“样本没有公式”等推测不能覆盖本次完整原文。

预览、最终确认及正式路线页都可展开“资料覆盖清单”，查看原文件、原文位置、对应课程和辅助资料理由。统计表示全部提取片段已进入处理并获得去向，**不是每个知识点都经过独立语义核验或每项事实都正确的保证**。长资料的模型摘要仍可能遗漏细节，重要规则应对照原文复核。

## 后续正文与数据

覆盖清单按原始文件ID、片段ID和课程位置保存。后续单课大纲与正文检索优先取回分配到本课的原片段；正文仍遵守既有3份资料、每份8段、合计19800字符预算，不把摘要直接作为事实引用。实际引用继续从原文取得并定位。

清单随SQLite、完整备份和课程分享保存，分享后的新课程ID不影响课程位置映射。删除课程同步清理清单。旧备份没有清单时仍兼容，不伪造“已完整覆盖”的标记。

## 调用、进度与边界

短资料直接规划，不增加全文整理调用。长资料每批先发起一次整理请求；仅当返回索引的编号、覆盖或字段长度等校验失败时，提供具体原因、遗漏片段ID、本批完整原文和限长旧索引，最多再调用一次模型修正当前批次。该修正可能额外计费，仍不合格就停止，不循环重试、不重做已成功批次；网络、鉴权、响应解析失败或手动取消不触发该修正。缓存损坏也不会触发付费修正。全部批次通过后再调用一次大纲生成；大纲覆盖或结构有误时仍最多修正一次。右下角显示读取资料与规划阶段，允许取消；取消后不保存部分大纲。资料导入界面提前说明等待及费用可能增加。

每批完整返回且校验通过后立即缓存。后续批次失败或被取消时，已完成批次仍可供用户下次主动重试复用；未完成、校验失败或取消后迟到的结果不缓存，不把部分索引当成完整大纲。不改变串行批处理或全部实质知识覆盖要求。

桌面端在数据目录的 `material-planning-cache.sqlite` 保存最近使用的最多256批索引，重启、重新导入相同文件后可复用；重新导入时间、学习目标和目录调整不改变资料索引。键由模型服务地址、协议、模型名称、JSON/思考/输出参数及每批原文、文件身份、索引规则版本和提示词计算；有关内容变化不复用旧批次，单纯修改等待超时或密钥不使索引失效。没有桌面持久化存储的服务仅保留本次运行的批缓存。

缓存只保存派生索引和哈希键，不保存API Key或完整原文，但索引仍可能包含资料中的敏感主题。缓存独立于课程，删除课程或丢弃资料不会立即删除索引，之后按容量淘汰；不包含在课程包或完整学习JSON中，可随整个数据目录备份。需清除时，先关闭应用，再移走 `material-planning-cache.sqlite` 及存在的同名 `-wal`、`-shm` 文件；清除后再生成会重新调用模型。缓存损坏或无法读写会明确报错，不静默重新计费。

大纲预览、目录调整和资料索引不设应用自动超时，桌面内部请求也取消默认五分钟响应等待限制；可手动取消。服务商或网络主动超时、断连仍会失败。

完整整理后输入超过180000字符会明确要求按章节拆分，不截断清单。该字符限制不等于模型上下文能力或token数保证；较小模型仍可能拒绝大输入。导入上限、现有3–12节路线及学习时长约束不变。这里的全文是成功提取的文字，不包括未提取图片、扫描文字或丢失的复杂排版；应先在资料预览中确认内容。
