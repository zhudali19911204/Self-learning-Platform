# 模型与可选服务配置

本文说明当前程序的接口适配和设置方式。模型名称、账号权限及套餐适用范围请以实际服务为准；配置保存成功不代表具备调用权限。

## 桌面版设置

在“设置与数据”中分别配置课程生成与答疑、事实核查模型、课程配图、AI 朗读。各项独立保存并立即生效，不读取 Web 模式的 `.env`。

1. 选择模型服务，填写服务端实际提供的模型 ID 和接口根地址。
2. 填写 API Key；本机或已部署服务没有鉴权时可留空。
3. 云端或局域网服务需关闭对应的“仅使用本机”选项，再保存。
4. 检查已保存的连接，再在课程中手动验证实际生成。

“仅使用本机”只允许 `localhost`、`127.0.0.1` 和 `::1`，不包含局域网地址。程序不会安装模型权重或启动 Ollama、LM Studio、vLLM 等推理服务。

已有密钥不会回显；留空保留，填写新值替换，点击“清除”后保存才删除。更换服务或地址不会自动复用旧密钥。密钥由系统安全存储加密，依赖当前系统用户；复制配置文件到另一台电脑不保证能解密。

文字模型按服务保存最近一套配置，图片模型按接口协议保存。切换选项可恢复对应参数，但必须保存才切换实际使用的服务。未保存的草稿只留在当前窗口内存；关闭窗口时会提醒。

## 文字模型

| 服务 | Web 的 `LLM_PROVIDER` | 程序预设根地址 |
| --- | --- | --- |
| Ollama | `ollama` | `http://127.0.0.1:11434` |
| LM Studio | `lmstudio` | `http://127.0.0.1:1234/v1` |
| vLLM | `vllm` | `http://127.0.0.1:8000/v1` |
| DeepSeek | `deepseek` | `https://api.deepseek.com` |
| 通义千问／百炼 | `qwen` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 自定义兼容接口 | `compatible` | 手动填写服务提供的根地址 |

地址不包含末尾的 `/chat/completions` 或 `/api/chat`。模型 ID 必须与控制台、模型列表或实际部署一致，不能只填写展示名称。远端地址、密钥和地域应匹配。

Ollama 使用原生 `/api/chat`；其他文字服务使用 Chat Completions 兼容接口。自定义服务需支持 `messages`、输出 token 上限及 `choices[0].message.content`，并能按指令返回 JSON。专有签名、其他响应协议或额外必填参数不保证兼容。

连接检查只发送固定短提示，验证鉴权和短 JSON 输出，云端可能计费；不发送课程或笔记，也不能代替长课程生成验证。检查输出预算不超过 1024 token，并尊重更低的已保存上限。

### 输出格式与思考模式

- JSON 模式：`auto` 对 Ollama、DeepSeek、千问使用对应格式设置；其他兼容服务主要通过提示词约束。`on` 强制格式参数，`off` 不传格式参数，但仍要求 JSON 输出。
- 自部署 Qwen 若因思考过程耗尽输出预算，可在高级设置将“模型思考”设为“关闭（Qwen 兼容服务）”。程序对兼容服务发送 `chat_template_kwargs.enable_thinking=false`，需要服务端模板支持；不支持时改回服务默认。
- “已连接模型，但输出被截断／只返回思考内容”表示请求已到达模型。请核对思考设置、输出上限和模型能力，避免反复更换地址。
- 事实核查及课程评分共用独立核查模型，不能与课程生成模型使用同一模型身份。

## 联网资料与在线搜图

课程联网搜索使用已保存的百炼文字模型、同源 `/responses` 接口及 `web_search` 工具；需要模型及账号支持。程序仅接受真实工具返回的来源，不把模型自行写出的网址当成搜索结果。详见 [联网资料辅助生成](course-source-assisted-generation.md)。

“课程配图”中的百炼网页搜图需单独启用，沿用当前百炼文字模型配置，通过 `web_search_image` 返回候选图片；Commons 为另一个可选图库。搜索结果不等于使用授权，下载前需核对来源与许可。搜索、预览和 AI 生成图片是不同操作，不会因为打开面板就自动生成图片。

## 课程配图

在“设置与数据 → 课程配图”中启用图片服务，模型、协议及 Key 独立配置。

| 协议 | 根地址与返回格式 |
| --- | --- |
| 通用兼容接口 | 填到版本根路径，例如 `http://127.0.0.1:8001/v1`；自动追加 `/images/generations`，支持 `data[0].b64_json` 或 `data[0].url` |
| 阿里百炼原生接口 | 填服务提供的 `/api/v1` 根地址；使用同步多模态生成接口，读取 `output.choices[].message.content[].image` |

本版百炼原生适配支持 `wan2.7-image`、`wan2.7-image-pro`、`qwen-image-3.0`、`qwen-image-3.0-pro`。尺寸须符合所选模型范围；界面填写 `宽x高`，原生请求会转换为接口所需格式。普通聊天接口不一定提供文生图能力。ComfyUI 工作流、异步任务轮询和流式图片结果暂不支持。

正文可先请求 AI 配图建议，再编辑提示词和图注；点击确认生成后才调用图片模型。每次生成一张，失败不自动重试。图片保存在本机，随课程包和完整学习备份导出。

URL 图片仅从同源地址、内置的服务结果域名或用户明确添加的精确域名下载，不携带模型密钥或 Cookie。若提示“下载地址不在允许范围内”：

1. 核对报错中的结果域名，在图片高级设置中追加可信的精确域名并保存。
2. 回到原配图面板，使用“仅重试下载”，不重新生成图片。

不要填通配域名或允许全部对象存储地址。检查图片服务主要查询模型列表，不代表文生图权限已验证。

## AI 朗读

本版语音适配支持 `qwen-audio-3.0-tts-plus` 原生接口，根地址为 `/api/v1`。默认音色为 `longanlingxin` 与 `longanlufeng`，可按角色分别调整；不创建克隆音色，不提供跟读评分。语音配置和密钥独立保存，不自动沿用文字或图片密钥。

1. 在课程右侧点击“AI 朗读”，选择或粘贴材料，核对角色及音色。
2. 点击“预览角色与缓存”：本机拆分材料，不合成、不计费。
3. 确认后仅生成未缓存的片段；手动播放或重听，支持调整播放速度。

每次材料最多 8000 字，最多拆为 16 段、每段最多 1500 字。失败停止后续请求，不自动重试；已生成且下载完成的音频保留。已有待下载链接时优先“仅重试下载”，不要重新合成。待下载链接只在本次运行内存中保留 30 分钟。

已缓存音频可离线重听，修改文本、模型、音色或合成参数会使用新缓存。音频不包含在课程包、Wiki Markdown 或完整学习 JSON 中；需保留时，在关闭应用后备份整个数据目录。

## Web 模式的 `.env`

仅用于 `npm run dev` / `npm start`。首次可复制 [.env.example](../.env.example) 为 `.env`，已有配置时直接编辑，避免覆盖密钥；修改后重启 Web 服务。

```dotenv
LLM_PROVIDER=ollama
LLM_MODEL=填写已安装模型的完整ID
LLM_BASE_URL=http://127.0.0.1:11434
LLM_API_KEY=
LLM_JSON_MODE=auto
LLM_THINKING_MODE=auto
LLM_MAX_TOKENS=8192
LLM_TIMEOUT_MS=120000
PORT=3000
```

| 参数 | 可选值／范围 |
| --- | --- |
| `LLM_PROVIDER` | 上表的六种服务标识 |
| `LLM_MODEL` | 实际可用的模型 ID；留空使用内置示例 |
| `LLM_BASE_URL` | 预设可留空，自定义兼容服务必须填写 |
| `LLM_JSON_MODE` | `auto`、`on`、`off` |
| `LLM_THINKING_MODE` | `auto`、`off` |
| `LLM_MAX_TOKENS` | 128–32768，默认 8192；这是输出预算，须符合模型实际能力 |
| `LLM_TIMEOUT_MS` | 1000–600000 毫秒，默认 120000 |

程序不会自动换用其他服务、模型或账号。供应商给出的专属地址可按当前协议填写，但保存通过不代表模型、套餐及实际使用方式已获授权；程序不会为解决失败自动切换到其他计费接口。
